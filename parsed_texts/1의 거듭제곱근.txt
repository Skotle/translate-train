1. 개요 [편집]
1의 거듭제곱근(root of unity) [2] 은 연산이 정의된 군 연산군 의 개념으로, 해당 연산을 유한 번 거듭하여 항등원 을 얻을 수 있는 원소들을 일컫는다. 이 개념을 복소수 의 곱셈 군 ( C × , ⋅ ) (\mathbb C^{\times}, \ \cdot \ ) ( C × , ⋅ ) 에 한정하여 생각하기도 한다.

2. 정의 [편집]
1의 거듭제곱근(Root of unity) 군 ( G , ⋅ ) (G, \ \cdot \ ) ( G , ⋅ ) 과 원소 a ∈ G a \in G a ∈ G 가 주어져 있을 때,

g n = a g^n = a g n = a
인 원소 g ∈ G g \in G g ∈ G 를 a a a 의 거듭 제곱근 (Root of a a a ) 혹은 제곱의 수를 강조하여 a \boldsymbol a a 의 n \boldsymbol{n} n 제곱근( n n n th root of a a a ) 이라고 한다. 특히, a a a 가 군 ( G , ⋅ ) (G, \ \cdot \ ) ( G , ⋅ ) 의 항등원 1인 경우 [3] g ∈ G g \in G g ∈ G 를 1의 거듭제곱근(Root of unity) 혹은 1의 n n n 제곱근( n n n th root of unity) 이라고 한다.

1의 거듭제곱근(Root of unity) z n = 1 z^n = 1 z n = 1 인 복소수 z ∈ C z \in \mathbb C z ∈ C 를 1의 거듭제곱근(Root of unity) 혹은 1의 n \boldsymbol{n} n 제곱근( n \boldsymbol{n} n th root of unity) 이라고 한다.

위에서 정의한 일반적인 군 ( G , ⋅ ) (G, \ \cdot \ ) ( G , ⋅ ) 를 곱셈군 ( C × , ⋅ ) (\mathbb C^{\times}, \ \cdot \ ) ( C × , ⋅ ) 로 한정한 버전이다. 물론 1이 아닌 임의의 복소수 a ∈ C a \in \mathbb C a ∈ C 의 n n n 제곱근도 생각할 수 있지만, 이는 a ∈ C a \in \mathbb C a ∈ C 의 한 n n n 제곱근에 1의 n n n 제곱근들을 곱한 형태로 전부 표현 가능하다. 그렇기 때문에 1의 n n n 제곱근들은 본질적인 거듭제곱근으로서의 의미를 가진다. 아래 예시는 전부 복소수체(의 부분군)에서 계산한 1의 거듭제곱근들이다.

또한 2제곱근과 3제곱근이 번갈아 나타나는 다중근호의 경우는 1의 7제곱근과 1의 9제곱근이 있다. 다만 환원 불능 이다.
