1. 개요 [편집]
素 因 數 分 解 ｜ prime factorization

자연수 를 소인수 들의 곱으로 나타내는 것을 말한다. 소수 를 처음 배우는 중학교부터 자주는 아니더라도 계속 쓰이는 기본적인 수학 도구. 모든 수가 소인수분해된 형태를 유일하게 가지고 있다는 것은 산술의 기본정리 로 증명된다.

'소인수분해'라는 명칭과 거듭제곱은 중학교 1학년에 가서야 언급되지만, 초등학교 5학년 때 약수와 배수를 구하기 위해 쓰인다.
원래는 집합을 배운 뒤에 배웠던 과정이다.

2. 소인수분해를 하는 방법 [편집]
이 문단에서는 1보다 큰 어떤 정수 N N N 이 주어졌을 때, 10진법 표기에서 약수 를 찾는 여러 가지 기술에 대해 소개한다. 먼저 사람의 입장에서 가장 쉬운 방법은 아래의 배수 판정법 을 이용하는 것이다. 정수 N N N 에 대해서, - 2의 배수 [1] : 일의 자리 숫자가 짝수. [2]
- 3의 배수: 각 자릿수의 합이 3의 배수.
- 4의 배수: 십의 자리가 홀수면 1의 자리가 2/6, 짝수면 0/4/8, 0 이하면 그냥 4의 배수
- 5의 배수: 일의 자리가 0이거나 5인 경우.
- 6의 배수: N N N 이 2의 배수이면서 3의 배수.
- 7, 11, 13의 배수: 일의 자리부터 세 자리씩 끊은 뒤, 각 부분을 교대로 빼고 더한 값이 7, 11, 13의 배수. [3] [4] [5]
- 8의 배수: 맨 뒤 세 자리가 000 또는 8의 배수.
- 9의 배수: 각 자릿수의 합이 9의 배수.
- 10의 배수: 일의 자리가 무조건 0.
- 10 n 의 배수: 가장 끝의 n개의 자리가 모두 0.
- 12의 배수: N N N 이 3의 배수이면서 4의 배수.
- 15의 배수: N N N 이 5의 배수이면서 3의 배수.
- 25의 배수: 맨 뒤 두 자리가 00 또는 25의 배수.
- 20의 배수: N N N 이 4의 배수이면서 5의 배수. [6]
- 30의 배수: N N N 이 5의 배수이면서 6의 배수. [7]
- 48의 배수: N N N 이 3의 배수이면서 16의 배수. [8]
- 72의 배수: N N N 이 8의 배수이면서 9의 배수.
- 27, 37의 배수: 일의 자리부터 3자리씩 끊은 뒤 이들을 모두 합한 결과가 27, 37의 배수인 수. [9] [10]

보다 일반적으로 n이 합성수이고, 소인수가 2개 이상일 때, n의 배수를 판별하는 방법은 d가 n의 유니타리 약수라고 했을 때 d와 n÷d의 공배수 여야 하므로 이 둘의 배수판정법을 동시에 만족해야 한다는 것이다.
또는 아래 정리를 사용할 수도 있다. 모든 합성수 n n n 에 대해, 1 < d ≤ n 1<d\le\sqrt{n} 1 < d ≤ n ​ 를 만족하는 약수 d d d 가 적어도 하나 존재한다.

증명은 아래와 같다. n n n 을 합성수라 하자. 그러면 n = a b , 1 < a , b < n n=ab,\,1<a,b<n n = ab , 1 < a , b < n 이다. 만약 a , b a,b a , b 가 둘 다 n \sqrt n n ​ 보다 크다면, n = n n < a b = n n=\sqrt n\sqrt n<ab=n n = n ​ n ​ < ab = n 이 되어 모순이다. 따라서 a , b a,b a , b 중 적어도 하나는 n \sqrt n n ​ 보다 같거나 작다.

이 정리에 의해 어떤 큰 수를 소인수분해 할 때, 그 수의 제곱근 보다 큰 수로 나눌 필요는 없다는 사실을 알 수 있다. 이는 노가다 를 통해 소인수분해를 하는 시간을 크게 단축시켜 준다.
