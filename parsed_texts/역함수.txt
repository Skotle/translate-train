1. 개요 [편집]
逆 函 數 / inverse function

어떤 함수 의 정의역과 치역 [1] 사이의 대응 관계를 거꾸로 한 함수를 말한다. 함수 f : X → Y f: X \to Y f : X → Y 가 전단사( 일대일대응 )이면 그 역함수 f − 1 : Y → X f^{-1}: Y \to X f − 1 : Y → X 를 생각할 수 있는데, 이는 집합 Y Y Y 의 원소 y y y 에 대해 f ( x ) = y f(x) = y f ( x ) = y 인 유일하게 존재하는 x x x 를 대응시키는 것이다. 즉, f ( x ) = y ⟺ f − 1 ( y ) = x f(x) = y \iff f^{-1}(y) = x f ( x ) = y ⟺ f − 1 ( y ) = x 이고, 함수의 정의 때문에 이는 f f f 가 전단사일 때밖에 생각할 수 없다. 전단사가 아닌 함수는 조각적 정의 나 복소해석학 에 기반한 해석적 확장 [2] 등을 사용해야 한다.

2. 엄밀한 정의 [편집]
집합 X , Y X, Y X , Y 에 대해 함수 f : X → Y f: X \to Y f : X → Y 는 ∀ x ∈ X ∃ ! y ∈ Y ( x , y ) ∈ f \displaystyle \forall x \in X \quad \exists! y \in Y \quad (x, y) \in f ∀ x ∈ X ∃ ! y ∈ Y ( x , y ) ∈ f 을 만족하는 이항 관계 f ⊆ X × Y f \subseteq X \times Y f ⊆ X × Y 로 정의된다. [3] 이에 대해 f f f 의 각 원소의 순서만 바꾼 역관계 f ⊤ ⊆ Y × X f^\top \subseteq Y \times X f ⊤ ⊆ Y × X 를 생각할 수 있다. 이것이 함수의 조건을 만족하면, 즉 ∀ y ∈ Y ∃ ! x ∈ X ( y , x ) ∈ f ⊤ \displaystyle \forall y \in Y \quad \exists! x \in X \quad (y, x) \in f^\top ∀ y ∈ Y ∃ ! x ∈ X ( y , x ) ∈ f ⊤ 을 만족하면 이를 f f f 의 역함수라고 하고 f − 1 f^{-1} f − 1 로 적는다.

앞에서 f f f 의 역함수가 존재하기 위한 조건은 ∀ y ∈ Y ∃ ! x ∈ X ( x , y ) ∈ f \displaystyle \forall y \in Y \quad \exists! x \in X \quad (x, y) \in f ∀ y ∈ Y ∃ ! x ∈ X ( x , y ) ∈ f 임을 알 수 있다. 그런데 임의의 y ∈ Y y \in Y y ∈ Y 에 대해 ( x , y ) ∈ f (x, y) \in f ( x , y ) ∈ f 인, 즉 f ( x ) = y f(x) = y f ( x ) = y 인 x ∈ X x \in X x ∈ X 가 존재하는 함수를 전사함수 라고 하고, 임의의 y ∈ Y y \in Y y ∈ Y 에 대해 ( x , y ) ∈ f (x, y) \in f ( x , y ) ∈ f 인 x ∈ X x \in X x ∈ X 가 존재하면 유일한 함수를 단사함수 라고 한다. 따라서 f f f 의 역함수가 존재할 필요충분조건 은 f f f 가 전단사 (bijectif)인 것이다.

이제 역함수를 다른 관점으로 정의하자. 전단사 함수 f : X → Y f: X \to Y f : X → Y 와 이의 역함수 f − 1 : Y → X f^{-1}: Y \to X f − 1 : Y → X 에 대해 다음이 성립한다. - f ( x ) = y f(x) = y f ( x ) = y 인 임의의 x ∈ X , y ∈ Y x \in X, y \in Y x ∈ X , y ∈ Y 에 대해, ( x , y ) ∈ f (x, y) \in f ( x , y ) ∈ f 에서 ( y , x ) ∈ f − 1 (y, x) \in f^{-1} ( y , x ) ∈ f − 1 , 즉 f − 1 ( y ) = x f^{-1}(y) = x f − 1 ( y ) = x 이므로 f − 1 ( f ( x ) ) = x f^{-1}(f(x)) = x f − 1 ( f ( x )) = x 이다. 따라서 f − 1 ∘ f f^{-1} \circ f f − 1 ∘ f 는 X X X 의 항등함수 이다.
- f − 1 ( y ) = x f^{-1}(y) = x f − 1 ( y ) = x 인 임의의 x ∈ X , y ∈ Y x \in X, y \in Y x ∈ X , y ∈ Y 에 대해, ( y , x ) ∈ f − 1 (y, x) \in f^{-1} ( y , x ) ∈ f − 1 에서 ( x , y ) ∈ f (x, y) \in f ( x , y ) ∈ f , 즉 f ( x ) = y f(x) = y f ( x ) = y 이므로 f ( f − 1 ( y ) ) = y f\bigl( f^{-1}(y) \bigr) = y f ( f − 1 ( y ) ) = y 이다. 따라서 f ∘ f − 1 f \circ f^{-1} f ∘ f − 1 은 Y Y Y 의 항등 함수이다.

이제 이의 역 이 성립함을 보인다. 함수 f : X → Y , g : Y → X f: X \to Y, g: Y \to X f : X → Y , g : Y → X 에 대해 g ∘ f g \circ f g ∘ f 는 X X X 의 항등 함수이고 f ∘ g f \circ g f ∘ g 는 Y Y Y 의 항등 함수라고 가정하자. 그러면 임의의 ( x , y ) ∈ f (x, y) \in f ( x , y ) ∈ f 에 대해 f ( x ) = y f(x) = y f ( x ) = y 에서 g ( y ) = g ( f ( x ) ) = x \displaystyle g(y) = g(f(x)) = x g ( y ) = g ( f ( x )) = x 이므로 ( y , x ) ∈ g (y, x) \in g ( y , x ) ∈ g 이다. 또한 임의의 ( y , x ) ∈ g (y, x) \in g ( y , x ) ∈ g 에 대해 g ( y ) = x g(y) = x g ( y ) = x 에서 f ( x ) = f ( g ( y ) ) = y \displaystyle f(x) = f(g(y)) = y f ( x ) = f ( g ( y )) = y 이므로 ( x , y ) ∈ f (x, y) \in f ( x , y ) ∈ f 이다. 따라서 g g g 는 f f f 의 역관계이다. 또한 g g g 는 함수이므로 f f f 의 역함수이다.

따라서 함수 f : X → Y f: X \to Y f : X → Y 의 역함수를 ‘ f − 1 ∘ f f^{-1} \circ f f − 1 ∘ f 는 X X X 의 항등 함수이고 f ∘ f − 1 f \circ f^{-1} f ∘ f − 1 는 Y Y Y 의 항등함수 인 함수 f − 1 : Y → X f^{-1}: Y \to X f − 1 : Y → X ’ 로 정의해도 상관없다. 오히려 역함수를 이렇게 정의하면 정의에서 집합의 원소 등의 개념을 사용하지 않았으므로, 범주론 에서 함수를 일반화한 개념인 사상 에 대해서도 같은 방식으로 역사상을 정의할 수 있다. 그래서 일반적으로는 이를 역함수의 정의로 사용한다. [4]

3. 성질 [편집]
역함수가 존재하는 함수 f : X → Y f: X \to Y f : X → Y 와 그 역함수 f − 1 : Y → X f^{-1}: Y\to X f − 1 : Y → X 에 대하여 다음이 성립한다. - 본 함수와 역함수의 합성 - f ∘ f − 1 f \circ f^{-1} f ∘ f − 1 는 Y Y Y 에서의 항등함수이다.
- f − 1 ∘ f f^{-1} \circ f f − 1 ∘ f 는 X X X 에서의 항등함수이다. [5]
- f f f 의 정의역과 공역이 실수 전체 집합이면, f ∘ f − 1 = f − 1 ∘ f = id ⁡ R f \circ f^{-1} = f^{-1} \circ f = \operatorname{id}_\R f ∘ f − 1 = f − 1 ∘ f = id R ​ (단, id ⁡ R \operatorname{id}_\R id R ​ 는 항등함수 )
- f ∘ f = f ∘ f − 1 = f − 1 ∘ f − 1 f \circ f = f \circ f^{-1} = f^{-1} \circ f^{-1} f ∘ f = f ∘ f − 1 = f − 1 ∘ f − 1 인 함수는 대합 (involution)이다.
- 역함수의 그래프 y = f − 1 ( x ) \boldsymbol{y = f^{-1}(x)} y = f − 1 ( x ) 의 그래프는 본 함수 y = f ( x ) \boldsymbol{y = f(x)} y = f ( x ) 와 y = x \boldsymbol{y = x} y = x 에 대하여 대칭 이다. - 이는 본 함수의 그래프가 ( x , f ( x ) ) (x, f(x)) ( x , f ( x )) 를 지나면, 역함수는 정의에 의하여 ( f ( x ) , x ) (f(x), x) ( f ( x ) , x ) 를 지나기 때문이다.
- 본 함수가 미분 가능한 함수이고 그 도함수 의 함숫값이 0 0 0 인 점이 있을 경우, 역함수의 도함수에서 대응점은 특이점 이 된다.
- 연속함수의 그래프와 그 역함수의 그래프의 교점 - 증가하는 연속함수의 그래프와 그 역함수의 그래프의 교점이 존재하면 그 점은 y = x y = x y = x 위에 있다.
- 감소하는 연속함수의 그래프와 그 역함수의 그래프의 교점의 개수는 홀수이며, 항상 y = x y = x y = x 위의 교점을 하나 가진다.

4. 도출 [편집]
역함수는 y = x y = x y = x 에 대칭이기 때문에, 다음과 같은 방법으로 역함수를 도출할 수 있다. - 본 함수의 x x x , y y y 의 자리를 바꾼다.
- 1의 식에서 다시 y y y 를 x x x 에 대한 식으로 정리하여 양함수 의 꼴로 나타낸다. [6]

예시 1. y = 3 x + 1 y = 3 x + 1 y = 3 x + 1 의 역함수
- 본 함수의 x x x , y y y 의 자리를 바꾼다. x = 3 y + 1 x = 3 y + 1 x = 3 y + 1
- 1의 식에서 다시 y y y 를 x x x 에 대한 식으로 표현함으로써 역함수를 얻는다. ⟹ 3 y = x − 1 ⟹ y = x − 1 3 \displaystyle \begin{aligned} & \implies 3 y = x - 1 \\ & \implies \boldsymbol{y = \frac{x - 1}{3}} \end{aligned} ​ ⟹ 3 y = x − 1 ⟹ y = 3 x − 1 ​ ​

예시 2. y = e x − 4 y = \mathrm{e}^{x - 4} y = e x − 4 의 역함수(단, e \mathrm{e} e 는 자연로그의 밑 )
- 본 함수의 x x x , y y y 의 자리를 바꾼다. x = e y − 4 x = \mathrm{e}^{y - 4} x = e y − 4
- 1의 식에서 다시 y y y 를 x x x 에 대한 식으로 표현함으로써 역함수를 얻는다. ⟹ ln ⁡ x = ln ⁡ e y − 4 = y − 4 ⟹ y = ln ⁡ x + 4 \displaystyle \begin{aligned} & \implies \ln x = \ln \mathrm{e}^{y - 4} = y - 4 \\ & \implies \boldsymbol{y = \ln x + 4} \end{aligned} ​ ⟹ ln x = ln e y − 4 = y − 4 ⟹ y = l n x + 4 ​

- 삼각함수 ↔ 역삼각함수

- 쌍곡선함수 ↔ 역쌍곡선함수

- 미분 ↔ 부정적분 [8]
