1. 개요 [편집]
multiplicateur de Lagrange · Lagrange multiplier · Lagrange 乘數法

주어진 영역에서 추가 제약 조건이 있는 다변수 실함수의 임계점 [1] 을 구하는 방법.

2. 상세 [편집]
열린 영역 U ∈ R n \mathcal{U} \in \mathbb{R}^{n} U ∈ R n 에서 정의된 다변수함수 f ( x 1 , x 2 , ⋯ , x n ) f(x_{1},\,x_{2},\,\cdots , x_{n}) f ( x 1 ​ , x 2 ​ , ⋯ , x n ​ ) 에 대하여 f f f 의 극점 x x x 에서는 그레이디언트

∇ f = 0 \boldsymbol{\nabla} f = \mathbf{0} ∇ f = 0
을 만족하여야 한다. 만약 주어진 영역이 열린 집합이 아니라 방정식으로 결정되는 영역

g 1 ( x ) = g 2 ( x ) = ⋯ = g k ( x ) = 0 g_{1}(x)=g_{2}(x)=\cdots = g_{k}(x)=0 g 1 ​ ( x ) = g 2 ​ ( x ) = ⋯ = g k ​ ( x ) = 0

이런 경우 라그랑주 승수법은 ∇ f \boldsymbol{\nabla}f ∇ f 가 ∇ g i \boldsymbol{\nabla}g_{i} ∇ g i ​ 의 선형 결합이 된다는 것으로 변경하면 충분하다는 것을 말해준다.

3. 진술 [편집]
두 일급함수

f : R n → R g : U → R \begin{aligned} f&: \mathbb{R}^n \rightarrow \mathbb{R} \\ g&: \mathcal{U} \rightarrow \mathbb{R} \end{aligned} f g ​ : R n → R : U → R ​
가 있을 때 U ⊂ R n \mathcal{U} \subset \mathbb{R}^n U ⊂ R n 는 열린집합이고, 상수 c c c 에 대하여

S = { X ∈ U ∣ g ( X ) = c } S=\left\{X \in \mathcal{U} | \ g\left(X\right)=c \right\} S = { X ∈ U ∣ g ( X ) = c }
라고 하자. 이때 f f f 를 S S S 에 제한한 함수

f ∣ S : S → R , X ⟼ f ( X ) {f|}_S : S \rightarrow \mathbb{R} , X \longmapsto f\left(X\right) f ∣ S ​ : S → R , X ⟼ f ( X )

∇ f ( P ) = λ ∇ g ( P ) \boldsymbol\nabla f\left(P\right) = \lambda \boldsymbol\nabla g\left(P\right) ∇ f ( P ) = λ ∇ g ( P )

다만, 위의 진술은 매우 '수학적인' 것이다. 응용수학이나 수리경제학 등에서는 라그랑주 함수

L = f − λ 1 g 1 − ⋯ − λ k g k \mathcal{L} = f - \lambda_1 g_1 - \cdots - \lambda_k g_k L = f − λ 1 ​ g 1 ​ − ⋯ − λ k ​ g k ​
에 대한 극값을 찾는

∇ x , λ L ( x , λ ) = 0 \boldsymbol{\nabla}_{x,\,\lambda} \mathcal{L}(x,\,\lambda) = \mathbf{0} ∇ x , λ ​ L ( x , λ ) = 0
의 형태로 종종 기술이 되기도 한다. 여기서 라그랑주 승수 λ i \lambda_i λ i ​ 들을 찾는다는 과정이 이 방법 이름의 유래. 실제로 이게 라그랑주 가 처음 생각한 방식이기도 했고, 라그랑지언 등에 응용되는 형태가 되기도 하지만. 물론 이렇게만 쓰면 수학에서 원하는 엄밀한 증명이 희생되고, 영역 S S S 에서 특이점 이 나오는 경우 등에선 잘 성립하지 않는다는 단점이 있다.

5. 사용 시 주의점 [편집]
라그랑주 승수법으로 극값 을 구할 때에는 몇 가지 주의점이 있다.
- 라그랑주 승수가 존재한다고 극점이 되는 것은 아니고, 주어진 점이 극대인지 극소인지 알려면 이계 도함수 판별법 [3] 을 사용해야 한다.

다변수함수 f ( x , y ) = x 2 − y 2 f(x,\,y)=x^2-y^2 f ( x , y ) = x 2 − y 2 같은 경우는 점 ( 0 , 0 ) (0,\,0) ( 0 , 0 ) 에서 그레이디언트가 0이지만, 그 점이 극점은 아니다. 제약조건이 없는 경우에는 그 점의 이계 도함수들을 나타내는 헤세 행렬 혹은 헤시안의 성질에 따른 이계 도함수 판별법을 사용한다. 헤시안이 양, 음의 정부호이면 각각 극대, 극소값을 지니고, 헤시안이 indefinite이면 극대도 극소도 아니다. [4]

마찬가지로 제약조건이 있는 라그랑주 승수법의 경우, 극대 및 극소값을 판별하기 위해서는 목표함수의 헤시안을 영역의 접평면 위에서 보아야 한다. 이를 보다 적은 계산으로 판별할 수 있는 '경계 헤시안'을 이용하는 이계 도함수 판별법이 보통 사용된다. 물론 이 이계 도함수 판별법이 실패할 때도 있다.

- 라그랑주 승수법은 영역 내부점에서의 극점만 잡아줄 수 있으므로, 경계점들은 따로 분석해야 한다.

라그랑주 승수법은 열린 영역에서만 성립한다. 즉 영역이 있으면 그 내부점들에서만 극값을 잡아줄 수 있다. 따라서 컴팩트인 영역이 있어 최댓값의 존재성이 보장된다고 해도, 그 영역의 경계에 최댓값이 나올 수가 있다. 위의 산술기하평균 예시의 영역

C = { ( x 1 , ⋯ , x n ) : x i ≥ 0 , x 1 + ⋯ + x n = n } C=\{(x_1,\,\cdots,\,x_n) : x_i \ge 0, \,x_1 + \cdots+x_n=n\} C = {( x 1 ​ , ⋯ , x n ​ ) : x i ​ ≥ 0 , x 1 ​ + ⋯ + x n ​ = n }
같은 경우는 영역의 경계에서 함수값이 0이어서 최댓값이 나오지 않았다. 하지만 만약 목표함수가 f = x 1 f = x_1 f = x 1 ​ 라면
