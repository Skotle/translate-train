1. 개요 [편집]
approximation

복잡한 수를 간단히 표현하기 위해 대략적인 범위를 추정하는 것.

추산(推算), 개산(槪算), 견적(見積)이라고도 한다.

2. 상세 [편집]
수학에서의 어림은 일의 자리부터 시작하여 그 정도에 따라 정한 자리까지 모두 0으로 표시함을 일컫는다. [1]

2.1. 용어 [편집]
어림에서 자리를 표현하는 방법은 '에서'와 '까지' 두 종류가 있다.

'에서'와 '까지'는 'from'과 'until'의 번역언데 'until'은 한국어로 '전까지'가 맞다. 따라서 어림에서의 '에서'는 해당 자리까지 포함하고 '까지'는 해당 자리 전까지 [2] 포함한다고 생각하면 된다.

가령, 만의 자리 에서 어림하라는 것은, 일의 자리부터 만의 자리까지 0으로 표시하라는 것이다. 반면, 만의 자리 까지 어림하라는 것은, 만의 자리 바로 오른쪽 자리까지, 즉 천의 자리까지만 0으로 표시하라는 것이다. [3] 10 n − 1 \boldsymbol{10^{n-1}} 1 0 n − 1 자리에서 어림하라는 것 은 10 n \boldsymbol{10^n} 1 0 n 자리까지 어림하라는 것 과 동치이다. (단, n n n 은 정수)

3. 종류 [편집]

3.1. 올림 [편집]
구하려는 자리 아래에 0이 아닌 수가 있으면 구하려는 자리의 수를 1 크게 하고, 그 아래 자리의 수를 모두 0으로 나타내는 것.

예를 들어 643을 백의 자리까지 올림한다고 가정하면, 백의 자리 미만의 숫자, 6 43 에서 0이 아닌 수가 있으므로 백의 자리의 수를 1일 올려 700으로 올림한다.

0.1258을 소수 둘째 자리까지 올림한다고 가정하면, 소수 둘째 자리 미만의 숫자, 0.12 58 에서 0이 아닌 수가 있으므로 소수 둘째 자리의 수를 1을 올려 0.13으로 올림한다.

주의할 것은 600을 백의 자리까지 올림하는 것과 같이 백의 자리 미만의 숫자 6 00 와 같이 1이 아닌 수가 없으면, 올리지 않고, 그대로 써서 600으로 쓴다.

3.2. 버림 [편집]
구하려는 자리 아래에 있는 0이 아닌 수를 모두 0으로 나타내는 것.

예를 들어 643을 백의 자리까지 버림한다고 가정하면, 백의 자리 미만의 숫자, 6 43 에서 0이 아닌 수가 있으므로 백의 자리의 수 미만의 수를 0으로 하여 600으로 버림한다.

0.1258을 소수 둘째 자리까지 버림한다고 가정하면, 소수 둘째 자리 미만의 숫자, 0.12 58 에서 0이 아닌 수가 있으므로 소수 둘째 자리 미만의 수를 버려 0.12로 버림한다.

구하려는 자리 아래가 모두 0이면 버리지 않지만, 버림을 하더라도 결과는 같다.

내림이라고도 한다.

4. 올림 및 버림 함수 [편집]
어림을 구하려는 수와 자릿수를 받기 때문에 셋 모두 이변수함수이다.

4.1. 올림 함수 [편집]
올림 함수는 다음과 같이 정의된다. roundup ⁡ ( x ; n ) = 10 − n ⌈ 10 n x ⌉ \displaystyle \begin{aligned} \operatorname{roundup}(x;n)=10^{-n} \lceil10^n x\rceil \end{aligned} roundup ( x ; n ) = 1 0 − n ⌈ 1 0 n x ⌉ ​

여기서 ⌈ ⋅ ⌉ \lceil \cdot \rceil ⌈ ⋅ ⌉ 은 천장 함수 이다.

4.2. 버림 함수 [편집]
버림 함수는 다음과 같이 정의된다. rounddown ⁡ ( x ; n ) = 10 − n ⌊ 10 n x ⌋ \displaystyle \begin{aligned} \operatorname{rounddown}(x;n)=10^{-n} \lfloor10^n x\rfloor \end{aligned} rounddown ( x ; n ) = 1 0 − n ⌊ 1 0 n x ⌋ ​

여기서 ⌊ ⋅ ⌋ \lfloor \cdot \rfloor ⌊ ⋅ ⌋ 은 바닥 함수 이다.

5. 올림·버림·반올림의 관계 [편집]
일반적인 반올림은 0, 1, 2, 3, 4에서는 버리고 5, 6, 7, 8, 9에서는 올리는 어림이기 때문에 0, 1, 2, 3, 4에서는 버림과, 5, 6, 7, 8, 9에서는 올림과 결과가 같아진다.

5.1. 함수의 관점에서 [편집]
위의 정의에 바닥 함수, 천장 함수가 들어가는데, 바닥 함수는 아래의 무한급수 [4] ⌊ x ⌋ = x − 1 2 + ∑ n = 1 ∞ sin ⁡ ( 2 n π x ) n π ( x ∉ Z ) \displaystyle \begin{aligned} \left\lfloor x\right\rfloor=x-\frac12 +\sum_{n=1}^\infty\frac{\sin{(2n\pi x)}}{n\pi}\quad\left(x\notin\mathbb Z\right) \end{aligned} ⌊ x ⌋ = x − 2 1 ​ + n = 1 ∑ ∞ ​ nπ sin ( 2 nπ x ) ​ ( x ∈ / Z ) ​

으로 정의되며, 천장 함수는 바닥 함수를 원점에 대칭시켜 유도할 수 있기 때문에 [5] 어림은 해석학 의 맥락으로 볼 수 있는 것이다. 이는 미분으로 어림하기 를 배울 때 더더욱 명확해진다.
