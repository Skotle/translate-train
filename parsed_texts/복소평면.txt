1. 개요 [편집]
복소평면 ( 複 素 平 面 , complex plane)은 복소수 의 집합 C \mathbb{C} C 를 좌표평면 R 2 \mathbb{R}^{2} R 2 에 나타내어 복소수를 직관적으로 이해할 수 있게 만든 도구이다. 가우스 평면, 복소수 평면 이라고도 하며, 프랑스 에서는 복소평면의 아이디어를 떠올린 사람 중 한 명인 장 로베르 아르강의 이름을 따서 아르강 다이어그램(Argand Diagram) [1] [2] 이라고 한다. 실직선 이 실수 에 대응한다고 보면 이해가 빠를 것이다.

2. 교육 과정 [편집]
- 대한민국 에서는 6차 교육과정 까지 수학 II '삼각함수와 복소수' 단원에서 복소평면을 배웠으나 빠졌다가 2015 개정 교육과정에서 실질적 과학고 전용 과목인 고급 수학Ⅰ [3] 으로 부활했다가 2022 개정 시에 다시 삭제되었다.
- 일본 에서는 이과생들이 이전까지는 수학Ⅲ 에서, 2022년 4월부터는 수학C 에서 배우고 있다. [4]
- 호주 에서는 대학 입시에 복소평면 부분이 역삼각함수 등과 함께 입시에 나온다.
- 영국 에서는 GCE A Level 에서 심화수학 Core 1에서 다루고, International A Level 에서 순수심화수학 1, 2에서 다룬다. [5]

3. 다색 복소평면 [편집]
바이어슈트라스 타원 함수 ℘ \wp ℘ 의 그래프

domain coloring

복소수 관련 자료 가운데 이런 알록달록한 그림을 볼 때도 있는데, 이게 복소함수의 그래프이다. 보통 명도 는 함숫값의 크기( 절댓값 )를 나타내며 [6] , 색도 는 편각 을 나타낸다.

편각을 나타내는 색의 기준점을 정하는 방법은 학자에 따라 몇 가지가 존재한다. 편각이 가질 수 있는 값의 범위가 일반적인 것처럼 0 0 0 과 2 π 2\pi 2 π 사이일 때는, 양의 실수를 색의 기준점인 빨간색 으로 잡고 음의 실수는 그 보색인 청록색 이 되는 방식이 많이 쓰인다. [7] [8]

필요에 따라 치역을 절댓값이나 허수부, 실수부를 취하여 3차원 직교좌표계 혹은 원통좌표계 상에서 연직 축 [9] 에 대응시켜 나타내기도 한다. 이 때에는 명도와 채도를 고정하여 나타낸다.

4. 평면과 복소수의 대응법 [편집]
복소수와 직교좌표평면의 점을 일대일로 대응시킬 수 있다. 예를 들어 x + i y x+iy x + i y 를 ( ℜ ( x + i y ) , ℑ ( x + i y ) ) = ( x , y ) \left(\Re (x+iy), \Im(x+iy)\right) = \left(x,y\right) ( ℜ ( x + i y ) , ℑ ( x + i y ) ) = ( x , y ) 에 대응시키면 이는 일대일 대응이 되고 벡터공간 구조를 보존해준다. 극좌표 평면상에서도 r e i θ = r ( cos ⁡ θ + i sin ⁡ θ ) = r θ re^{i \theta} = r \left( \cos \theta + i \sin \theta \right) = r \phase \theta r e i θ = r ( cos θ + i sin θ ) = r θ ​ 으로 표현할 수 있음에 따라 이러한 성질을 만족시킨다.

i i i 는 ( 0 , 1 ) \left(0,\,1\right) ( 0 , 1 ) 에, 1 1 1 은 ( 1 , 0 ) \left(1,\,0\right) ( 1 , 0 ) 에 대응되기 때문에, x축을 실수축, y축을 허수축이라 부른다.

해당 점과 원점과의 거리 는 해당 복소수의 절댓값 이 된다.

5. 덧셈 관련 [편집]

5.1. 덧셈의 기하적 표현 [편집]
언급했듯이, 벡터공간의 성질을 유지하며 C \mathbb{C} C 를 R 2 \mathbb{R}^{2} R 2 에 대응시켰기 때문에, 두 복소수의 덧셈은 복소평면에서 두 벡터의 덧셈이 된다. 예를 들어, 두 복소수 a + b i , c + d i a+bi,c+di a + bi , c + d i 를 더하면 복소평면에서는 두 위치벡터 [10] ( a . b ) , ( c , d ) (a.b),(c,d) ( a . b ) , ( c , d ) 의 합이므로 평행사변형법을 써서 구할 수 있다.

5.2. 켤레 [편집]
복소수 z z z 의 켤레복소수 z ˉ \bar{z} z ˉ 는 z z z 의 x축 대칭이다.

참고로 어떤 복소수의 반수는 원점 대칭, 어떤 복소수의 반수의 켤레복소수는 y축 대칭이다.

5.3. 실수, 순허수 [편집]
실수와 순허수는 각각 x x x 축과 y y y 축 위에 있다. [11]
