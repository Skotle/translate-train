1. 개요 [편집]
밀러-라빈 소수판별법(Miller-Rabin primality test) [1] 은 입력으로 주어진 수가 소수 인지 아닌지 페르마의 소정리 를 변형하여 확률적으로 판별하는 알고리즘이다.

2. 원리 [편집]
페르마의 소정리 에 의하여 p p p 가 소수이면 임의의 정수 a a a 에 대하여 a p ≡ a ( m o d p ) a^p\equiv a\pmod p a p ≡ a ( mod p ) 가 성립하고, a a a 와 p p p 가 서로소 이면 a p − 1 ≡ 1 ( m o d p ) a^{p-1}\equiv 1\pmod p a p − 1 ≡ 1 ( mod p ) 이 성립한다.

p p p 가 홀수 소수라면 p − 1 = d × 2 s p - 1 = d \times 2^s p − 1 = d × 2 s 라 할 수 있고( s s s 는 양의 정수, d d d 는 홀수), a p − 1 ≡ 1 ( m o d p ) a^{p-1}\equiv 1\pmod p a p − 1 ≡ 1 ( mod p ) 는 곧 a d × 2 s ≡ 1 ( m o d p ) a^{d \times 2^s}\equiv 1\pmod p a d × 2 s ≡ 1 ( mod p ) 이다.

따라서 어떤 홀수 N N N 이 소수인지 판단하고자 할 때, 먼저 N − 1 = d × 2 s N - 1 = d \times 2^s N − 1 = d × 2 s 의 형태로 분해한다. 이후 a d m o d N a^{d} \bmod N a d mod N 을 계산하고, 이를 바탕으로 a d × 2 r m o d N a^{d \times 2^{r}} \bmod N a d × 2 r mod N 값을 순차적으로 구해 나간다. 이 과정은 나머지가 1 1 1 또는 N − 1 N-1 N − 1 이 나타날 때까지 반복한다.

이때 처음 계산한 a d m o d N a^{d} \bmod N a d mod N 에서부터 시작하여, 나머지가 1 1 1 이거나, 혹은 다른 값이 나오다가 N − 1 N-1 N − 1 이 등장한 뒤 바로 다음 단계에서 1 1 1 로 넘어가는 경우에는 알고리즘을 무사히 ‘통과’한 것으로 간주하며, 이때 N N N 은 “아마도 소수”로 판단된다.

3. 알고리즘 [편집]
위 내용을 다음과 같은 유사 코드로 정리할 수 있다.
알고리즘 MR (밀러-라빈 소수판별법) : 홀수 N > 3 N > 3 N > 3 이 소수인지 판별한다.
MR1. N − 1 = d × 2 s N - 1 = d \times 2^s N − 1 = d × 2 s ( d d d 는 홀수)로 분해한다.
MR2. a a a 를 2 ≤ a ≤ N − 2 2 \leq a \leq N - 2 2 ≤ a ≤ N − 2 범위에서 무작위로 선택한다.
MR3. x ← a d m o d N x \leftarrow a^d \bmod N x ← a d mod N
MR4. x = 1 x = 1 x = 1 또는 x = N − 1 x = N - 1 x = N − 1 이면 "아마도 소수"를 출력하고 종료한다.
MR5. r ← 1 r \leftarrow 1 r ← 1
MR6. r ≥ s r \geq s r ≥ s 이면 "명백한 합성수"를 출력하고 종료한다.
MR7. x ← x 2 m o d N x \leftarrow x^2 \bmod N x ← x 2 mod N [4]
MR8. x = N − 1 x = N - 1 x = N − 1 이면 "아마도 소수"를 출력하고 종료한다.
MR9. r ← r + 1 r \leftarrow r + 1 r ← r + 1 . MR6으로 간다.
