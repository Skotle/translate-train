특정 x x x 값에서의 함숫값과는 상관 없이, 독립변수 가 해당 값(argument)에 가까워질수록 종속변수 가 한없이 지향하는 값을 말하는 것이기 때문에, 극한값이 함숫값으로 존재하지 않아도 상관이 없는 것이다. 극한의 엡실론-델타 정의에 따르면 x = a x=a x = a 부근(해당 지점 제외)에서 극한값 L L L 과 어떠한 양의 실수 ε \varepsilon ε 만큼의 차이도 나지 않는 함숫값이 존재해야 한다는 뜻이기 때문이다. 때문에 정확한 함숫값이 존재하지 않는 경우에 극한값이 근삿값과 비슷한 의미라고 오해받는 경우가 많다. 하지만 오차 범위에 따라서 다양한 값이 전부 근삿값이 되지만, 오차로 어떠한 실수를 잡더라도 해당 성질이 성립하는 값은 극한값 한 가지 밖에 없고, 오차가 어떠한 양의 실수보다 작기 때문에 실수체계에서는 해당 오차가 유일한 무한소 인 0 0 0 으로 정의된다.

비표준 해석학 에서는 0 0 0 이 아닌 무한소가 무수히 많이 존재하지만, 유한 초실수는 실수와 무한소의 합으로 표현하는 방법이 항상 한 가지이기 때문에 해당 실수값이 무조건 하나로 정해진다. 때문에 비표준 해석학으로 봤을 때에는 오차가 무한소인 근삿값에 비유할 수도 있으나, 무한소를 표준화 했을 때에는 항상 0이 되기에, 실수 범위에서는 오차가 0 0 0 이외에 다른 수일 가능성이 없다. 이러한 무한소를 이용한 극한의 연산 테크닉은 공대에서 자주 사용하지만, 초실수체의 도입 없이 엄밀하지 않게 시행되는 경우가 많기에 수학적 엄밀함에 있어서는 주의를 요하는 방법이다.

2.4. 비표준 해석학 에서의 정의 [편집]
엡실론-델타가 나온 이래, 무한소라는 존재는 별 주목을 받지 못하게 되다가, 다시 150년 후인 20세기 후반에 아브라함 로빈슨, Detlef Laugwitz 등의 수학자가 실수에서 성립하는 1차 논리 문장으로 표현 가능한 명제는 모두 그대로 성립하면서 무한소와 무한대를 포함하는 수체계인 초실수체 라는 엄청난 물건을 가지고, 비표준 해석학이란 해석학 의 새로운 분야를 만들었다. 비표준 해석학에서는 엡실론-델타 대신 무한소를 이용하여 해석학의 정리들을 똑같이 증명할 수 있다.
