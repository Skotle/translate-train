1. 개념 [편집]
多 變 數 函 數 / function of several variables, multivariate function

독립변수가 두 개 이상인 함수.

가장 기본적인 꼴의 함수 는 y = f ( x ) y=f(x) y = f ( x ) 꼴로, 독립변수가 한 개이다. 이런 함수는 변수 x x x 와 변수 y y y 가 직접적인 영향을 주고받으며, y y y 가 종속변수가 되는 가운데 독립변수는 x x x 단 하나이다. 또한, 변수의 개수는 여러 개일 수 있으므로 두 개, 세 개 그 이상으로 늘어나도 무방하다. 하나의 종속변수를 제외한 나머지 변수가 독립변수가 되므로 이 경우 독립변수가 두 개 이상이 된다.

z = f ( x , y ) z=f(x, y) z = f ( x , y ) 꼴이 되는 변수가 세 개인 다변수 함수는, 좌표평면 에 x x x 축과 y y y 축에 동시에 수직이 되고 원점을 지나는 z z z 축을 도입하여 3차원 좌표공간 에 그래프로 나타낼 수 있다. 이때 그래프를 나타내기 위해 등고선 , 밀도 그래프 [1] 등을 이용할 수 있다. 정다포체 처럼 차원 이 4 이상인 도형은 실제로 현실 세계에다가 그리기 어렵고 복잡하므로 변수가 4개 이상인 다변수 함수는 3차원 좌표공간 축에다가 축을 하나 이상 더하는 등의 방법으로 그래프로 나타낼 수 있다. 그러나 초기하함수 처럼 집합 을 변수로 하는 함수는 해당 변수를 좌표축으로 둘 수 없다.

다변수 함수는 다변수 실함수(function of several real variables)와 다변수 복소함수(function of several complex variables)로 나뉜다. 큰 맥락으로는 벡터 함수, 텐서 함수 등도 포괄한다.

이 문서에서는 편의상 다변수 함수 중 가장 간단한, 독립변수가 두 개인 다변수 함수로 여러 정보를 설명 하며, 임계점, 극대·극소, 변곡점, 안장점과 같은 개념들은 그 다변수 함수를 그래프로 나타낼 수 있음을 전제하며, 따라서 함수의 변수도 세 개임을 전제하는 셈임을 기억하라.

n n n 변수함수의 n n n 은 보통 독립변수의 개수를 뜻한다. 즉, 이변수함수는 z = f ( x , y ) z=f(x, y) z = f ( x , y ) 꼴의 함수를 의미한다.

2. 다변수 함수가 되기 위한 조건 [편집]
식 y = f ( x ) y=f(x) y = f ( x ) 가 함수가 되려면, f f f 의 정의역에 속하는 x x x 에 값에 대해 오직 하나의 y y y 값이 f f f 의 치역에 존재해야 한다.

이와 마찬가지로, 식 z = f ( x , y ) z=f(x,y) z = f ( x , y ) 가 함수가 되려면, f f f 의 정의역에 속하는 ( x , y ) (x,y) ( x , y ) 로 이루어진 순서쌍 각각에 대해 오직 하나의 z z z 값만이 f f f 의 치역에 존재해야 한다. 이 경우 x x x 와 y y y 는 독립변수, z z z 는 종속변수가 된다. x x x 라는 독립변수의 값이 달라지지 않았는데 z z z 의 값이 달라졌다고 해서 함수가 아니라고 단정할 수 없다. y y y 의 값이 달라졌다면 순서쌍 ( x , y ) (x,y) ( x , y ) 가 결국 달라진 것이므로, 함수가 될 수 있다. 함수가 아닌 경우는 x x x 와 y y y 의 값이 모두 달라지지 않았는데 z z z 의 값이 달라질 수 있는 경우이다. 이 경우는 순서쌍 ( x , y ) (x,y) ( x , y ) 가 달라지지 않기 때문이다.

여기서 종속변수도 순서쌍일 경우 벡터 함수가 된다.

6. 임계점 [편집]

6.7. 이계도함수 판정법 [편집]
함수가 임계점 p p p 근방에서 이계 미분이 존재할 경우, 헤세 행렬 (Hessian matrix 또는 Hesse-matrix) 혹은 헤시안 (Hessian)은 이계도함수들을 모아놓은 다음의 대칭행렬로 정의된다. H e s s ( f ) = ( ∂ 2 f ∂ x i ∂ x j ) i , j = 1 , ⋯ , n \displaystyle \mathrm{Hess}(f) = \left(\frac{\partial^2 f} {\partial x_i \partial x_j} \right)_{i,j=1,\cdots, n} Hess ( f ) = ( ∂ x i ​ ∂ x j ​ ∂ 2 f ​ ) i , j = 1 , ⋯ , n ​ 대칭행렬에 대한 스펙트럼 정리 에 의해, n변수 다변수 함수의 헤세 행렬은 항상 대각화가 가능하며 n개의 고윳값을 갖는다. 이들 고윳값의 부호가 특정 조건을 만족시킬 경우 임계점의 특성을 다음과 같이 판정할 수 있다. 이계도함수 판정법/헤세 판정법 (Second derivative test)
다변수 함수가 임계점 p p p 근방에서 모든 이계도함수가 존재하고 연속일 때( C 2 C^2 C 2 ), - 헤세 행렬의 고윳값이 모두 양수이면(즉 양정치(positive definite)이면) p p p 는 극대점이다.
- 헤세 행렬의 고윳값이 모두 음수이면(즉 음정치(negative definite)이면) p p p 는 극소점이다.
- 헤세 행렬이 양수 고윳값과 음수 고윳값을 모두 갖고 있으면, p p p 는 안장점 이다.

이상의 경우에 해당하지 않으면 이계도함수 판정법을 사용할 수 없다.

고윳값이 반정치(semidefinite)인 경우에는 안장점 및 극점이 되는 것이 모두 가능하다. 예를 들어 f ( x , y ) = x 2 + k y 4 f(x,y) = x^2 + ky^4 f ( x , y ) = x 2 + k y 4 같은 경우 헤세 행렬은 항상 양반정치(positive semidefinite)이지만, 점 ( 0 , 0 ) (0,0) ( 0 , 0 ) 은 k < 0 k<0 k < 0 이면 안장점이 되고, k ≥ 0 k \ge 0 k ≥ 0 이면 극대점이 된다. 다만 양수 고윳값이 있으면 적어도 극소점이 될 수는 없다는 것은 증명할 수 있다.

이계도함수 판정법의 증명은 다변수 테일러 정리 를 2차항까지 전개하여 진행된다.
