1. 개요 [편집]
perturbation theory · 攝 動 理 論

섭동 이론이란 원래 물리학 전반에서 정확한 해가 잘 알려진 어떤 계에 미세한 변화를 줬을 때 그 해가 어떻게 변화하는지를 수학적으로 풀어내기 위한 도구인데, 특별한 경우가 아니면 보통 양자역학에서의 섭동 이론을 지칭하게 된다. 따라서 본 문서에서도 양자역학의 섭동 이론에 대해 기술한다.

이 문서에서는 양자역학적 연산자 표기에 사용되는 hat( ^ \hat{\,\,\,} ^ )은 따로 붙이지 않았음에 유의한다.

2. 시간에 무관한 섭동 이론 [편집]

2.1. 비축퇴 섭동 이론 [편집]
본래 계의 해밀토니언 H ( 0 ) \mathcal{H}^{(0)} H ( 0 ) 을 알고 있고, 여기에 섭동 해밀토니언이 가해져서 분석해야 할 계의 해밀토니언이 다음과 같은 형태가 됐다고 가정하자.

H = H ( 0 ) + H ′ \begin{aligned} \mathcal{H}=\pmb{\mathcal{H}}^{(0)}+\pmb{\mathcal{H}}' \end{aligned} H = H ( 0 ) + H ′ ​
이때, 섭동 해밀토니언은 시간에 의존하지 않으며, H ( 0 ) ≫ H ′ \boldsymbol{\mathcal{H}^{(0)} \gg \mathcal{H}'} H ( 0 ) ≫ H ′ 이라고 가정한다. 자연계에서 이 섭동 해밀토니언이 들어가게 되면 그 고유 상태를 해석적으로 알아내는 것이 가능한 경우는 굉장히 제한적이다. 이때 다음과 같은 λ \lambda λ 라는 인자를 붙이는데, 일단 여기서는 λ < 1 \lambda < 1 λ < 1 이라고 가정하자. 이러한 방법을 시간에 무관한 섭동 이론(time-independent perturbation theory) 이라고 한다. 이후 λ → 1 \lambda \to 1 λ → 1 로 놓아 본래의 해밀토니언으로 되돌릴 것이다. 그렇게 되면, 해밀토니언은 λ \lambda λ 에 대한 함수가 된다.

H = H ( 0 ) + λ H ′ \begin{aligned} \mathcal{H}=\mathcal{H}^{(0)}+\lambda \mathcal{H}' \end{aligned} H = H ( 0 ) + λ H ′ ​
