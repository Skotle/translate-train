Bézout's Identity [1]

1. 개요 [편집]
베주 항등식(Bézout's Identity)은 두 정수 와 그 최대공약수 사이의 관계를 보여주는 항등식 이다. 그 내용은 다음과 같다.
적어도 둘 중 하나는 0이 아닌 정수 a , b a, b a , b 가 있다. 그리고 a a a 와 b b b 의 최대공약수를 d d d 라고 하자. 이때, 다음 세 명제가 성립한다.
1. d = a x + b y d= ax + by d = a x + b y 를 만족하는 정수 x , y x, y x , y 가 반드시 존재한다.
2. d d d 는 정수 x , y x, y x , y 에 대하여 a x + b y ax+by a x + b y 형태로 표현할 수 있는 가장 작은 자연수이다.
3. 정수 x , y x, y x , y 에 대하여 a x + b y ax+by a x + b y 형태로 표현되는 모든 정수는 d d d 의 배수이다.

위 세 명제 중 메인은 1번이며, 1번을 증명하는 과정에서 2번 명제와 3번 명제가 따라서 증명된다.

2. 증명 [편집]
증명은 다음과 같은 순서로 진행된다. 자세한 과정은 아래에 있다. 1. a x + b y ax + by a x + b y 꼴로 표현할 수 있는 가장 작은 자연수가 존재함을 밝힌다. 그것을 d d d 라고 하자.
2. d d d 는 a a a 와 b b b 의 공약수임을 밝힌다.
3. a a a 와 b b b 의 공약수는 d d d 의 약수가 되어야 함을 밝힌다.

2.1. 단계 1 [편집]
둘 중 적어도 하나는 0이 아닌 정수 a a a , b b b 가 있다. 이때 다음과 같은 집합 S S S 를 정의하자.

S = { m ∣ m = a x + b y > 0 , x ∈ Z , y ∈ Z } S = \left\{ m | m = ax + by > 0, x \in \mathbb{Z}, y\in \mathbb{Z} \right\} S = { m ∣ m = a x + b y > 0 , x ∈ Z , y ∈ Z }

먼저 S ≠ ∅ S \ne \varnothing S  = ∅ 임을 보이자. 만약 a > 0 a > 0 a > 0 라면 ∣ a ∣ = a × 1 + b × 0 ∈ S \left| a \right| = a \times 1 + b \times 0 \in S ∣ a ∣ = a × 1 + b × 0 ∈ S 이다. 만약 a < 0 a < 0 a < 0 라면 ∣ a ∣ = a × ( − 1 ) + b × 0 ∈ S \left| a \right| = a \times (-1) + b \times 0 \in S ∣ a ∣ = a × ( − 1 ) + b × 0 ∈ S 이다. 만약 a = 0 a = 0 a = 0 라면 b ≠ 0 b \ne 0 b  = 0 이라서 앞서 a의 경우와 같은 논리로 ∣ b ∣ ∈ S \left| b \right| \in S ∣ b ∣ ∈ S 이다. 따라서 집합 S S S 는 ∣ a ∣ \left| a \right| ∣ a ∣ 와 ∣ b ∣ \left| b \right| ∣ b ∣ 중 적어도 하나를 원소로 가지므로 S ≠ ∅ S \ne \varnothing S  = ∅ 이다.

집합 S S S 는 정의에 따라서 자연수의 부분집합이다. S ≠ ∅ S \ne \varnothing S  = ∅ 이므로 자연수의 정렬성(Well-ordering Principle) [2] 에 의해 집합 S S S 는 가장 작은 원소를 가진다.

∴ \therefore ∴ 집합 S S S 의 최소 원소, 즉 a x + b y ax + by a x + b y 꼴로 나타낼 수 있는 가장 작은 자연수는 존재한다. 그것을 d d d 라고 부르자.

2.2. 단계 2 [편집]
S S S 의 정의에 의해, 어떤 정수 k , l k, l k , l 에 대하여 d = a k + b l d = ak +bl d = ak + b l 이다.

S S S 에 속하는 임의의 원소 x x x 에 대하여 만약 x x x 가 d d d 의 배수가 아니라고 가정하자. [3] 나눗셈 정리 에 의해, x = q d + r ( 0 ≤ r < d ) x = qd + r (0 \le r < d) x = q d + r ( 0 ≤ r < d ) 라고 할 수 있다. 그렇다면 나머지 r r r 은 0이 아닌 0 < r < d 0 < r < d 0 < r < d 인 자연수이다. 그리고 x x x 는 집합 S S S 의 원소이므로 x = a u + b v , u ∈ Z , v ∈ Z x = au + bv, u \in \mathbb{Z} , v \in \mathbb{Z} x = a u + b v , u ∈ Z , v ∈ Z 라고 할 수 있다.
r = x − q d = ( a u + b v ) − q ( a k + b l ) = a u − a q k + b v − b q l = a ( u − q k ) + b ( v − q l ) ∈ S r = x - qd = (au + bv) - q(ak + bl) = au - aqk + bv - bql = a(u - qk) + b(v - ql) \in S r = x − q d = ( a u + b v ) − q ( ak + b l ) = a u − a q k + b v − b q l = a ( u − q k ) + b ( v − q l ) ∈ S [4]

r r r 은 x x x 를 d d d 로 나누었을 때 나머지이므로 d d d 보다 작다. 앞서 d d d 를 집합 S S S 에서 가장 값이 작은 원소로 정의했음에도 d d d 보다 작은 S S S 의 원소인 r r r 이 존재하는 것은 d d d 의 최소성을 위반하므로 모순이다. 따라서 처음의 가정인 " x x x 가 d d d 의 배수가 아니다."는 거짓이다. 따라서 x x x 는 d d d 의 배수이다.

x x x 는 집합 S S S 의 임의의 원소이므로 집합 S S S 의 모든 원소는 d d d 의 배수이다. 따라서 a a a 혹은 b b b 가 0이 아닌 정수 일 경우 ∣ a ∣|a| ∣ a ∣ 혹은 ∣ b ∣|b| ∣ b ∣ 가 집합 S S S 의 원소이기 때문에 d d d 를 약수로 갖는다. 한편 a a a 혹은 b b b 가 0일 경우 0이 아닌 모든 수는 0의 약수이기 때문에 d d d 를 약수로 갖는다. 따라서 d d d 는 a a a 와 b b b 의 공약수이다.

2.3. 단계 3 [편집]
만약 e e e 가 a , b a,b a , b 의 공약수라고 하자. a = a ′ e , b = b ′ e a=a'e, b = b'e a = a ′ e , b = b ′ e 이면 d = a k + b l = e ( a ′ k + b ′ l ) d = ak+bl = e(a'k+b'l) d = ak + b l = e ( a ′ k + b ′ l ) 이므로, e e e 는 d d d 의 약수이다. 따라서 a , b a,b a , b 의 모든 공약수는 d d d 의 약수이므로, d d d 는 약수 중에서 가장 큰 최대공약수이다.

4. 일차 부정방정식 과의 연관성 [편집]

5. 확장 [편집]
베주 항등식은 변수가 하나인 다항식 에 대해서도 성립한다. 위의 a , b , d a, b, d a , b , d 를 모두 최고차항이 1인(monic) 다항식으로 바꾸고, '가장 작은 자연수' 를 '차수가 가장 작은 다항식'으로 바꾸자. 물론 x , y x,y x , y 는 monic일 필요는 없다. 다만 위의 증명은 유리수, 실수, 복소수 계수에서만 성립한다. 정확히는 계수가 체 의 범위에 있을 때. 증명도 위와 거의 동일한데, S S S 의 정의를 a x + b y ax+by a x + b y 꼴의 모든 다항식으로 놓고, 차수가 가장 작은 monic 다항식을 d d d 로 고르면 된다. [5] 다항식에서도 나눗셈 정리 가 나머지 정리 라는 이름으로 그대로 먹히기 때문.
