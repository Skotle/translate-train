2. 설명 [편집]
이 명제 의 진위를 헷갈리는 이유는 정확한 용어의 정의 없이 직관 만으로 논증하려 했기 때문이다. 가령 무한 소수 라는 것을 점점 다가가는 수 같은 식의 임의로 움직인다는 개념을 집어넣곤 하는데 수학에 다가가는 수라는 개념은 정의되지 않는다. 원주율 을 3.141592 ⋯ 3.141592\cdots 3.141592 ⋯ 라고 쓴다고 해서 이것이 원주율에 다가가는 수가 아니듯이 말이다.

대한민국의 경우 일반적으로 고등학생 때 극한 을 수박 겉 핥기 식으로만 배우게 되며 수학 교사 들 중에서도 해석학 을 심도 있게 배운 사람이 적다 보니 [1] 고등학교 수학 과정에서 문이과를 불문하고 잘못 이해하고 넘어가기 십상이다.

이러한 논리에는 어쩔 수 없는 부분도 있는데 무한대 라는 개념부터 엄밀히 하기에는 갈 길이 멀고 [2] 해석학이란 학문 자체가 수학의 근본 중 하나 [3] 인 만큼 고등학교 수준으로는 작정하고 제대로 배우기가 매우 어렵다. 이렇다 보니 어쩔 수 없이 극한의 개념 역시 앞서 설명한 '무한히 가까워지는'이라든지 '다가가는' 같은 적당한 오류 를 허용하면서 가르칠 수밖에 없는 상황이다. 거칠게 말하면 수학 교육학 이라는 분야는 청소년들이 수포자 가 되지 않도록 이런 엄밀하지 않은 논리를 어느 정도까지 용인할 것인지 고민하는 학문이니 일선 수학 교사들은 교육학을 잘 모르는 비사범 계열 수학 전공자들의 지적이 억울할 수 있다. 비슷한 예로는 초등학교 수학에서는 음수 개념을 배우지 않아 크기가 작은 자연수에서 큰 자연수를 뺄 수 없다고 가르치고, 중학교 수학에서는 ( − 1 ) × ( − 1 ) = 1 (-1)\times(-1)=1 ( − 1 ) × ( − 1 ) = 1 문제에 대해 증명 을 생략하고 참으로 정의된 개념이라고 가르치며, 고등학교 수학 과정에 들어가기 전까지는 허수 를 배우지 않기에 중학교 수학에서는 제곱해서 음수가 되는 것은 불가능하다고 배운다. [5] 이렇듯 학습자의 수준을 고려한 적당한 오류는 불가피한 것이다.

다만 0.999 ⋯ 0.999\cdots 0.999 ⋯ 라는 표기는 엄밀한 표현 [6] 의 문제일 뿐 직관적인 표기 [7] 에 대해 염려할 것은 없다. 이러한 표기에 유한 소수인 0.999 ⋯ 9 0.999\cdots9 0.999 ⋯ 9 같은 것을 들이미는 것은 혼란만 심화될 뿐이다. 순환 마디 위에 점을 찍어 나타내는 표기를 쓰면 더욱 명확한데 0.999 ⋯ = 0. 9 ˙ ≠ 0.999 ⋯ 9 0.999\cdots = 0.\dot9 \ne 0.999\cdots9 0.999 ⋯ = 0. 9 ˙  = 0.999 ⋯ 9 이다.

정수 부분이 0이고 순환마디가 9인 무한소수를 0.999 ⋯ 9 0.999\cdots9 0.999 ⋯ 9 이런 식으로 표기하기로 약속했다면 모르겠으나, 일반적으로 중간에 ⋯ \cdots ⋯ 이 있고 끝에 숫자가 적혀져 있는 것은 중간을 생략하고 끝을 표기했다는 것을 나타내는 것으로 본다. 즉, 0.999 ⋯ 9 0.999\cdots9 0.999 ⋯ 9 는 소수점 아래 9가 유한개이고, 그 이후 자리부터는 9가 아니라 0이 반복되는 것이라고 생각해야 한다. 그러므로 0.999… = 1, 0.999…9 = 0.999…9000… 이런 식이라는 것이다.

3. 증명 [편집]

3.1. 수학적 증명 [편집]
다행히도 0.999 ⋯ = 1 0.999\cdots=1 0.999 ⋯ = 1 이라는 사실은 수학적으로 아주 간단하게 증명할 수 있다. 대학교 기초 수준의 수학 지식이 있다면 이해하는 데에 무리는 없을 것이다.

0.999 ⋯ 0.999\cdots 0.999 ⋯ 과 같은 표기를 쓰기 전에 일단 ' 무한 소수 '라는 것이 무엇인지를 알 필요가 있다. 정의는 간단하다. 자연수 n n n 에 대하여 수열 { a n } \{a_n\} { a n ​ } 을 생각하자. 만약에 알아보고 싶은 무한 소수가 0.999 ⋯ 0.999\cdots 0.999 ⋯ 라고 한다면 a 1 = 0.9 , a 2 = 0.99 , a 3 = 0.999 , ⋯ a_1 = 0.9,\,a_2 = 0.99,\,a_3 = 0.999,\,\cdots a 1 ​ = 0.9 , a 2 ​ = 0.99 , a 3 ​ = 0.999 , ⋯ 이 될 것이다. 무한 소수라는 것은 이러한 수열의 극한 으로서 정의된다.

간단히 설명하자면, a n a_n a n ​ 의 극한이 a a a 라는 것은 어떤 양수 ε \varepsilon ε 에 대하여, n n n 이 어떤 자연수 N N N 보다 크면 a n a_n a n ​ 과 a a a 의 차이가 ε \varepsilon ε 보다 작아지는 자연수 N N N 이 존재한다는 것, 달리 말하자면 N N N 을 ε \varepsilon ε 의 함수 N ( ε ) N(\varepsilon) N ( ε ) 으로 나타낼 수 있음 을 의미한다. 직관적으로도 이 정의는 우리가 일상적으로 말하는 '무한히 접근한다'라는 표현과 일맥상통함을 이해할 수 있을 것이다. 이 정의를 만족하지 않고도 a n a_n a n ​ 가 a a a 로 무한히 접근할 방법이 있을까 고민해 본다면 명확하다.

첫 번째 문제는 수열 { a n } \{a_n\} { a n ​ } 의 극한값이 존재하는지에 대한 것이다. 두 번째 문제는 이 극한값이 무엇인지에 대한 문제이다. 다행히도, 임의의 무한 소수에 대해 수열 { a n } \{a_n\} { a n ​ } 의 극한값은 존재하고, 그 극한값은 이 수열의 상한(supremum), 풀어 쓰면 '모든 자연수 n n n 에 대해 a n a_n a n ​ 보다 크거나 같은 숫자의 집합에서 가장 작은 수'와 같다.

이를 증명하기는 어렵지 않다. 일단 집합 A = { a n ∣ n ∈ N } A=\{a_n \mid n\in\mathbb{N}\} A = { a n ​ ∣ n ∈ N } 이 상계(upper bound)를 가진다는 것을 보이자. 예를 들어 ' 10 10 10 '은 임의의 a n a_n a n ​ 보다 크거나 같으므로 이 집합의 상계이다. 실수 의 완비성에 의해 공집합 이 아닌 실수의 부분 집합에 상계가 존재한다면 상한(supremum = least upper bound) [8] 은 언제나 존재한다. 수학자들이 부등호를 적절하게 조절하여 임의의 집합에 대해서도 항상 존재할 수밖에 없도록 만든 개념이라서 그렇다. 이는 하한(infimum = greatest lower bound)도 마찬가지. 자세한 것은 링크 를 참조.

5. 논란이 발생하는 이유 [편집]

5.1. 교육 과정상의 문제 [편집]
현재 한국 중등 교과의 순환 소수 도입에서 0.999 ⋯ = 1 0.999\cdots=1 0.999 ⋯ = 1 의 문제를 논하는 것은 금기시되고 있다. 교육부 및 평가원의 2015 개정 교육 과정 고시 [25] 에는 대놓고 "유한 소수를 순환 소수로 나타내는 것은 다루지 않는다."라고 교수 학습 유의 사항에 명시되어 있다. 유한 소수를 순환 소수로 나타낼 수 있는 경우는 X X X . X X 999 ⋯ XXX.XX999\cdots X X X . X X 999 ⋯ 같은 꼴이 유일하기 때문에, 이건 누가 봐도 이 문제를 저격한 것이다. 그다음 항목이 바로 "순환 소수를 분수로 고치는 것은 순환 소수가 유리수임을 이해할 수 있는 정도로 다룬다"이다.

순환 소수의 개념이 상당히 느슨하게 다루어지고 있지만, 소수가 나오는 수준을 생각하면 이게 교육적으로는 올바른 방법이다. 초등 교과에서 제기된 소수의 나눗셈에 대한 의문을 [26] 조금이나마 풀어주면서 한편으로는 실수 에 대한 도입 역할로서 무한 소수를 소개하는 정도에 그쳐야 하는데, 이런 상황에서 극한이니 뭐니 하며 만리장성을 쌓으려 들면 바로 수포자 를 양산하는 악순환이 시작된다. 실제로 1960년대~1970년대 즈음에 아동·청소년의 인지 능력이나 심리적 발달 주기 따위는 알 바 아니라는 듯이 오로지 학술적 엄밀함만을 강조하는 본질주의적 수학 교육이 유행했으나 결과적으로 수포자만 늘어났던 전례가 있다. [27] 이런 교육학 적 고찰 [28] 도 없이 0.999 ⋯ = 1 0.999\cdots=1 0.999 ⋯ = 1 에 대한 오해의 원인을 무작정 교사들이 멍청하다거나 엄밀한 정의를 가르치지 않는 교육 과정이 틀려먹었다고 단순하게만 주장하는 일부 수학도들의 비판은, 사실상 비판이라기보다는 부당하고 모욕적인 '비난'에 가깝다. 수학 교사는 일자무식 좆문가 가 절대 아니다. 내용을 몰라서 못 가르치는 게 아니라, 학생을 가르치는 교육자로서 아직 성숙하지 않은 청소년에게 이를 무턱대고 가르치다간 역효과만 나기 때문에 안 가르치는 것이고 대한민국 수학 교육 과정에서도 이를 금기시하는 것이다.

문제는 이 0.999 ⋯ 0.999\cdots 0.999 ⋯ 의 존재를 생각하지 않으면서 오개념이 발생하는 위험이다. 대부분의 사람들이 극한의 정의에만 매몰되어 0.999 ⋯ = 1 0.999\cdots=1 0.999 ⋯ = 1 에 불편함을 느끼는 심리적인 이유를 간과하는데, 바로 수의 기수법 표현이 유일하다는 고정 관념 이다. 사실 0.999 ⋯ = 1 0.999\cdots=1 0.999 ⋯ = 1 을 보면 바로 '어 생각해 보니 그러네'라는 소리가 나오긴 하지만, 이 점을 생각하지 않는다면 이건 0.999 ⋯ = 1 0.999\cdots=1 0.999 ⋯ = 1 을 알고 있는 사람도, 심지어 수학 전공자들도 가끔씩 착각하는 오개념이다. 또한 저 식은 유한 소수 표현이랑 순환 소수 표현이 같아질 수 있다는 것을 의미하기도 하며 애초에 유한 소수라는 개념이 특정 진법 에서 소수점 아래에서 끝에 오는 0 \bf0 0 은 생략한다는 인위적인 약속에 의해 생겨난 작위적인 개념 이며 소수점 아래에서 특정 자릿수 이후로 0 \bf0 0 이 반복되는 무한 소수를 다르게 부르는 것 에 불과하다. [29] 즉 유한 소수와 순환 소수는 칼같이 나누어질 수 있는 게 아니고, 실수의 하위 분류는 더더욱 아니다. 수의 표현과 수의 차이를 엄밀히 구분하지 못하는 것은 추상성이 충분히 발달하지 못한 초/중등 과정에서 흔히 발생하는 오개념 중 하나이다. 하지만 0.999 ⋯ = 1 0.999\cdots=1 0.999 ⋯ = 1 은 상기한 오개념들의 '유일한' 반례이기 때문에, 10진법 외의 진법을 배우지 않는 한 이것만 없으면 모든 실수를 소수 표현으로 유일하게 나타내고, 유한 소수/순환 소수의 분류 기준을 엄밀히 세우는 것이 그럴듯해 보이는 착각을 준다. 이런 상황에서 기존의 고정 관념을 지키고자 한다면 0.999 ⋯ = 1 0.999\cdots=1 0.999 ⋯ = 1 을 부정하기 위해 이상한 논리를 만들어내게 되는 것이다.
