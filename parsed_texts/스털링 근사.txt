스털링 근사는 계승 , 나아가 감마 함수 에 대한 근삿값 을 구할 수 있도록 하는 식으로, 스털링 공식 이라고도 한다. 제1종 스털링 수 , 제2종 스털링 수 의 제임스 스털링(James Stirling, 1692~1770)이 연구한 개념이다. 일반적으로는 아래와 같은 식으로 표현되며 n ! ≈ 2 π n ( n e ) n ln ⁡ ( n ! ) ≈ n ln ⁡ n − n \begin{aligned} n! &\approx \sqrt{2\pi n} \Bigl( \frac ne \Bigr)^n \\ \ln(n!) &\approx n\ln n-n \end{aligned} n ! ln ( n !) ​ ≈ 2 π n ​ ( e n ​ ) n ≈ n ln n − n ​
