폴란드계 프랑스인 수학자인 가스통 줄리아 가 고안한 프랙털 의 일종으로, 다음과 같은 점화식 으로 표현되는 수열 { z n } \{z_n\} { z n ​ } 의 절댓값이 무한대로 발산 하지 않는 복소수 c의 집합으로 정의된다. z n + 1 = z n 2 + c \begin{aligned} \ z_{n+1} &=z_n^2+c \end{aligned} z n + 1 ​ ​ = z n 2 ​ + c ​
위의 점화식은 망델브로 집합 과 유사하지만, 망델브로 집합 은 z 0 = 0 + 0 i \begin{aligned} \ z_{0} &=0+0i \end{aligned} z 0 ​ ​ = 0 + 0 i ​ 일 때 z를 발산하지 않게 하는 c의 집합이라는 점이 다르다. 즉, z와 c의 역할이 뒤바뀐 것이다.

줄리아 집합은 망델브로 집합과 동일하게 자기유사성을 가지며 가까운 두 점이 서로 다른 양상을 보이는 초기 조건의 민감성도 띤다.
