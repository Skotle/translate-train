1. 개요 [편집]
Rolle's theorem
미분 가능한 함수에 대한 정리로 12세기 인도의 바스카라 2세 에 의해 처음 발견되었으며, 17세기 미셸 롤(Michel Rolle)에 의해 처음으로 증명되었다. 처음 증명한 수학자의 이름을 따 롤의 정리라고 부른다. 미분 가능한 함수에서 같은 함수 값을 가지는 두 점 a a a , b b b 가 있을 때 구간 ( a , b ) \left(a,b\right) ( a , b ) 에서 접선의 기울기(= 미분계수)가 0 0 0 이 되는 점이 적어도 하나 있다는 내용을 담는다. 즉 더욱 엄밀하게 설명하면 다음과 같다.
함수 f : [ a , b ] → R f:\left[a, b\right] \rightarrow \mathbb R f : [ a , b ] → R 가
1) 닫힌구간 [ a , b ] \left[a,b\right] [ a , b ] 에서 연속이고
2) 열린구간 ( a , b ) \left(a,b\right) ( a , b ) 에서 미분가능하며
3) f ( a ) = f ( b ) f\left(a\right)=f\left(b\right) f ( a ) = f ( b ) 이면, f ′ ( c ) = 0 f'\left(c\right)=0 f ′ ( c ) = 0 을 만족하는 c ∈ ( a , b ) c\in\left(a,b\right) c ∈ ( a , b ) 가 존재한다.

이를 기하학적으로 보면 이렇다. 함수 f ( x ) f\left(x\right) f ( x ) 가 닫힌구간 [ a , b ] \left[a,b\right] [ a , b ] 에서 연속이고 열린구간 ( a , b ) \left(a,b\right) ( a , b ) 에서 미분가능할 때, 곡선 y = f ( x ) ( a ≤ x ≤ b ) y=f\left(x\right) \left(a\leq x\leq b \right) y = f ( x ) ( a ≤ x ≤ b ) 에서 접선의 기울기가 0 0 0 이 되는 점 ( c , f ( c ) ) \left(c,f\left(c\right)\right) ( c , f ( c ) ) 가 적어도 1개 존재한다.

2. 증명 [편집]
1. 함수 f : [ a , b ] → R f:\left[a, b\right] \rightarrow \mathbb R f : [ a , b ] → R 이 상수함수일 경우, 임의의 x ∈ ( a , b ) x\in \left(a, b\right) x ∈ ( a , b ) 에 대해 f ′ ( x ) = 0 f'\left(x\right)=0 f ′ ( x ) = 0 이다.
따라서 f ′ ( c ) = 0 f'\left(c\right)=0 f ′ ( c ) = 0 을 만족하는 c ∈ ( a , b ) c\in\left(a,b\right) c ∈ ( a , b ) 가 존재한다.

2. 함수 f : [ a , b ] → R f:\left[a, b\right] \rightarrow \mathbb R f : [ a , b ] → R 이 상수함수가 아닐 경우, f ( a ) = f ( b ) ≠ f ( x ) f\left(a\right)=f\left(b\right)\ne f\left(x\right) f ( a ) = f ( b )  = f ( x ) 인 x ∈ ( a , b ) x\in \left(a, b\right) x ∈ ( a , b ) 가 존재한다.
그런데 f f f 는 닫힌구간 [ a , b ] \left[a,b\right] [ a , b ] 에서 연속이므로 최대·최소의 정리 에 의해 이 구간내에서 최댓값과 최솟값을 가진다. (ⅰ) f ( a ) = f ( b ) < f ( x ) f\left(a\right)=f\left(b\right)< f\left(x\right) f ( a ) = f ( b ) < f ( x ) 인 x ∈ ( a , b ) x\in \left(a, b\right) x ∈ ( a , b ) 가 존재한다고 하자. [1] 그러면 f f f 는 열린구간 ( a , b ) \left(a, b\right) ( a , b ) 에서 최댓값을 가져야 한다. x = c x=c x = c 에서 최댓값 f ( c ) f\left(c\right) f ( c ) 를 가진다고 하면, 임의의 x ∈ [ a , b ] x\in \left[a, b\right] x ∈ [ a , b ] 에 대해 f ( x ) − f ( c ) ≤ 0 \displaystyle f\left(x\right)-f\left(c\right)\leq 0 f ( x ) − f ( c ) ≤ 0 이다. 그러면 다음이 성립한다.

lim ⁡ x → c − f ( x ) − f ( c ) x − c ≥ 0 \displaystyle\lim_{x\to c-}\frac{f(x)-f(c)}{x-c}\geq0 x → c − lim ​ x − c f ( x ) − f ( c ) ​ ≥ 0

그런데 x = c x=c x = c 에서 f f f 는 미분가능하므로 두 값이 같아야 한다. 따라서 f ′ ( c ) = 0 f'\left(c\right)=0 f ′ ( c ) = 0 이 성립한다. (ⅱ) x = c x=c x = c 에서 최솟값 f ( c ) f\left(c\right) f ( c ) 를 가질 때, 똑같은 방법으로 f ′ ( c ) = 0 f'\left(c\right)=0 f ′ ( c ) = 0 이 성립한다.

3. 활용 [편집]
롤의 정리를 일반화하여 평균값 정리 [2] 로 나타낼 수 있다. 반대로 평균값의 정리에서 f(a) = f(b) 인 경우가 롤의 정리이다.

대학에서 미적분학을 배운다면 롤의 정리는 실근의 유일성(uniqueness)을 증명할 때 쓴다. [3] 간단히 과정을 서술하면 근의 개수를 판별할 함수를 f라 하자. 사잇값의 정리 를 이용해 실근의 존재함을 보인 후 f의 실근이 a,b (단, a<b)라고 가정하자. 여기서 f는 [a, b]에서 연속이면서 (a, b)에서 미분가능한 함수여야 한다. 이 때, 롤의 정리에 의해 (a, b)에서 f'의 값이 0인 점이 존재해야 한다. 이때 구간 (a,b)에 속하는 c에 대해 f'(c)=0이 아님을 보이면 귀류법에 의해 f가 2개 이상의 실근을 가질 수 없음을 보일 수 있다.

롤의 정리를 이용하여 로피탈의 정리 를 증명할 수 있다. 롤의 정리를 이용하지 않으면 난이도가 상승하므로, 기초 미적분학 수준에서는 롤의 정리를 보조정리 로 사용하여 증명하게 된다.
