1. 개요 [편집]
metric space / 距 離 空 間

거리함수 를 통해 임의의 거리를 부여한 집합 으로, 노름공간 등 거리가 정의되는 여러 공간의 일반적인 추상화 형태라고 볼 수 있다.

3. 유사거리 [편집]
pseudometric

거리공간과 거의 비슷하나, 서로 다른 두 점 사이의 거리가 0이 될 수 있는 공간이다. 구체적으로, 거리함수의 정의가 다음과 같이 바뀐다. - d ( x , x ) = 0 d(x, x) = 0 d ( x , x ) = 0
- d ( x , y ) = d ( y , x ) d(x, y) = d(y, x) d ( x , y ) = d ( y , x )
- d ( x , z ) ≤ d ( x , y ) + d ( y , z ) d(x, z) \leq d(x, y) + d(y, z) d ( x , z ) ≤ d ( x , y ) + d ( y , z )

대칭성과 삼각부등식 조건은 동일하나, 일반 거리함수에서는 iff로 정의되어 d ( x , y ) = 0 d(x, y) = 0 d ( x , y ) = 0 이라면 반드시 x = y x = y x = y 였지만, 유사거리에서는 반드시 x = y x = y x = y 가 아닐 수도 있다.
