1. 개요 [편집]
다가 함수 ( 多 價 函 數 , multivalued function)는 여러 값을 갖는 함수이다. 함수의 기본적인 정의 중 '상의 유일성'에 어긋나므로 진짜 함수는 아니지만, 역함수 및 역상과 밀접한 연관이 있어 편의상 '함수'라는 명칭을 사용한다.

일반적으로, 함수 는 정의역의 한 원소에는 치역의 한 원소만이 대응한다. 예를 들어 항등함수 i d R \mathrm{id}_\mathbb R id R ​ 의 경우, i d R ( 1 ) = 1 \mathrm{id}_\mathbb R(1)=1 id R ​ ( 1 ) = 1 한 가지 값만을 갖는다. 그런데 복소해석학 을 배우다 보면, 여러 가지 값을 갖는 함수가 필요하다. 예를 들어, 편각 arg ⁡ \arg ar g 는 arg ⁡ ( 1 + i ) = π / 4 , 9 π / 4 , ⋯ \arg(1+i)=\pi/4, 9\pi/4,\cdots ar g ( 1 + i ) = π /4 , 9 π /4 , ⋯ 로 무수히 많은 값을 갖는다.

2. 심화 [편집]
정의역이 X X X 이고 치역이 Y Y Y 인 다가 함수는, 실질적으로 X → P ( Y ) \ ∅ X\to\mathcal P(Y)\backslash \emptyset X → P ( Y ) \∅ [1] 라고 생각할 수 있다. 즉, 정의역의 원소를 치역의 원소들의 모임, 즉 치역의 부분집합에 대응시키는 함수로 보는 것이다. 이 경우, 로그 함수 는 다음과 같이 생각할 수 있다.

log ⁡ ( x ) = { y ∈ C ∣ e y = x } \log(x)=\{y\in\mathbb C|e^y=x \} lo g ( x ) = { y ∈ C ∣ e y = x }
이때 다가 함수 f : X → P ( Y ) \ ∅ f:X\to \mathcal P(Y)\backslash \emptyset f : X → P ( Y ) \∅ 의 주욧값은 ∀ x ∈ X , g ( x ) ∈ f ( x ) \forall x\in X, g(x)\in f(x) ∀ x ∈ X , g ( x ) ∈ f ( x ) 인 함수 g : X → Y g:X\to Y g : X → Y 로 정의된다.
선택 공리 하에서, 다가 함수의 주욧값은 항상 존재하는데, f : X → P ( Y ) \ ∅ f:X\to \mathcal P(Y)\backslash \emptyset f : X → P ( Y ) \∅ 의 치역 r a n g e ( f ) \mathrm{range}(f) range ( f ) 의 선택함수 C C C 와 f f f 의 합성 C ∘ f C\circ f C ∘ f 가 f f f 의 주욧값이기 때문이다.

2.1. 분지 절단 [편집]
복소 해석학에서 로그 함수를 정의할 때, Arg ⁡ ( Log ⁡ z ) ∈ ( − π , π ] \operatorname{Arg}(\operatorname{Log}z)\in(-\pi, \pi] Arg ( Log z ) ∈ ( − π , π ] 이도록 한다. 이렇게 편각에 따라 주욧값을 정하는 것을 분지 절단(branch cut)이라고 한다.

2.2. 리만 곡면 [편집]
f ( z ) = z 1 / 2 f(z) = z^{1/2} f ( z ) = z 1/2 | f ( z ) = arcsin ⁡ z f(z) = \arcsin z f ( z ) = arcsin z

리만 曲 面 / Riemann surface / Riemannsche Fläche

다가 함수는 말 그대로 함숫값을 그리는 그래프 가 여러 개이나, 이를 하나의 곡면 으로 이어붙일 수 있는데 이 이어붙인 곡면을 리만 곡면 이라고 한다. 이 개념을 제시한 베른하르트 리만 의 이름을 땄다. 사원수의 연산을 이해하기 위해 사용되기도 한다.

3. 예시 [편집]
대부분의 다가 함수는 음함수 의 역함수에서 나온다. - e y = x e^y = x e y = x 에서 log ⁡ \log lo g 와 주욧값 L o g \rm Log Log
- y n = x y^n = x y n = x 에서 x 1 / n x^{1/n} x 1/ n 과 주욧값 x n \sqrt[n]x n x ​

오일러의 공식 에 의해서 1 = e 2 n π i 1 = e^{2n\pi i} 1 = e 2 nπ i 이다. 그래서, 대부분의 함수에서 곱셈의 항등원 1을 곱한 뒤, 이 식을 대입하면 다가함수로 바뀌어 버린다. 물론 이 식은 모든 자연수 n 에 대해서 같은 값이 나오지만, 이 식이 지수함수나 복소로그함수에 결합되는 순간, 서로 다른 값을 가지는 다가함수로 바뀌게 된다.

4. 다가 함수 vs. 집합값 함수 [편집]
앞서 심화 문단에서 보았듯이 다가 함수는 근본적으로 정의역의 원소 하나가 치역의 멱집합의 원소(=치역의 부분집합)에 대응하는 것과 같기 때문에, 다가 함수를 '집합값 함수(set-valued function)'와 차이를 두지 않는 저자들도 간혹 존재한다. 그러나 '다가 함수'라는 명칭은 집합값 함수의 일종으로서 보통 대수학이나 복소해석학에서 사용되는 경향이 있다.

Wriggers and Panatiotopoulos (2014) [2] 는 여러 값에 대응하는 정의역의 원소만 추렸을 때 이 집합이 유한집합, 혹은 가산 무한집합일 때 다가 함수, 비가산 무한집합일 때 집합값 함수라고 칭했다. 이 정의에 의하면, 원의 방정식 같은 음함수 자체가 집합값 함수라는 명칭을 부여받는다.
