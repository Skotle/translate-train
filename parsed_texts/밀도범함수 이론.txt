1. 개요 [편집]
Density Functional Theory(DFT)

N N N 개의 전자로 이루어진 분자의 파동함수 를 표현하는데 필요한 변수는 공간에 관한 좌표 3 N 3N 3 N 개, 스핀에 관한 좌표 N N N 개로 총 4 N 4N 4 N 개의 좌표가 필요한데 이를 자유도(Degree of Freedom)라고 부른다. N N N 이 커질수록(= 전자의 수가 늘어날수록) 자유도가 커지게되고 파동함수는 우리가 필요한 정보 이상을 가지기도 하며 직관적으로 물리적 의미를 파악하기도 어려워진다. 그렇기에 파동함수 보다 더 적은 변수를 가지는 함수를 이용해 에너지나 다른 변수들의 기댓값을 구하려는 시도가 계속되었고, 그중 가장 친숙하면서도 유명한 이론이 전자 밀도 를 이용한 밀도범함수 이론(Density Functional Theory, DFT) 이다. 후술하겠지만 바닥 상태의 전자 밀도를 정확하게 안다면 신기하게도 계의 모양 [1] 이 하나로 정해지며 원론적으론 파동함수를 계산하지 않고도 모든 물리량의 기댓값을 계산할 수 있다! 물론 원론적으로만 그렇고 실제 전자 밀도를 실험 없이 바로 얻어낼 방법은 없으므로 이를 근사적으로 얻을 방법을 찾는 것이 DFT의 핵심이다.

해당 문서에선 퍼텐셜이 시간에 따라 변하지 않는 static DFT에 대해서만 다룬다.

7. 하트리-포크 방법 과의 비교 [편집]
- 근사 유무
하트리-포크 방정식은 오비탈 근사를 도입했기 때문에 방정식을 정확하게 풀더라도 항상 분자의 실제 에너지보다는 높게 나온다(HF limit) 하지만 콘-샴 방정식의 경우 v x c v_{xc} v x c ​ 만 정확하다면 정확한 에너지를 내어준다. [61]
- 개선의 방향성
하트리-포크 방법의 경우 들뜬 상태의 Slater Determinant를 추가해 줌으로써 정확한 해에 다가갈 수 있다. 하지만 DFT의 경우 v x c v_{xc} v x c ​ 를 개선하는 정해진 가이드라인이 없다.
- 변분 원리
하트리-포크 방정식의 경우 오비탈 근사 이외에는 사용한 근사가 없기에 변분 원리 를 따른다. DFT 또한 제2정리에 의해 변분 원리 를 따르지만 v x c v_{xc} v x c ​ 를 근사해서 넣기에 구한 에너지가 참값보다 작게 나올수도 있다.
