2. 복소수의 극형식 [편집]
복소평면에 대한 자세한 내용은 복소평면 문서를 참고하십시오.

임의의 복소수 z z z 를 고려하자. 2차원 평면을 고려할 때, 가로축을 복소수 z z z 의 실수부 ℜ ( z ) \Re(z) ℜ ( z ) , 세로축을 복소수 z z z 의 허수부 ℑ ( z ) \Im(z) ℑ ( z ) 로 설정하면, 복소수 z z z 는 점 P \rm P P 에 대응된다.

이때, 다음이 성립한다.

ℜ ( z ) = O P ‾ cos ⁡ θ ℑ ( z ) = O P ‾ sin ⁡ θ O P ‾ = ∣ z ∣ arg ⁡ ( z ) = θ \begin{aligned} \Re(z)&= \overline{\rm OP} \cos{\theta} \\ \Im(z)&= \overline{\rm OP} \sin{\theta} \\ \overline{\rm OP}&=|z| \\ \arg(z) &= \theta \end{aligned} ℜ ( z ) ℑ ( z ) OP ar g ( z ) ​ = OP cos θ = OP sin θ = ∣ z ∣ = θ ​
한편, ∣ z ∣ 2 = z z ˉ|z|^{2}= z \bar{z} ∣ z ∣ 2 = z z ˉ (단, z ˉ \bar{z} z ˉ 는 z z z 의 켤레 복소수) 형태로 구할 수 있다. θ \theta θ 를 복소수 z z z 의 편각 이라 하고, 기호로 arg ⁡ ( z ) \arg(z) ar g ( z ) 라 나타낸다.

이상에서 복소수 z z z 는 다음과 같은 형태로 쓸 수 있는데 [1] , 이것을 복소수의 극형식 이라 한다. 이는 극좌표계 에서 점 ( ∣ z ∣ , θ ) (|z|,\theta) ( ∣ z ∣ , θ ) 에 대응된다.

z = ∣ z ∣ ( cos ⁡ θ + i sin ⁡ θ ) \begin{aligned} z=|z| (\cos{\theta}+i\sin{\theta}) \end{aligned} z = ∣ z ∣ ( cos θ + i sin θ ) ​

2.1. 회전 변환 [편집]
우선 삼각함수의 덧셈정리 에 의해 다음 식을 얻는다.

( cos ⁡ θ + i sin ⁡ θ ) ( cos ⁡ α + i sin ⁡ α ) = cos ⁡ ( θ + α ) + i sin ⁡ ( θ + α ) \begin{aligned} (\cos{\theta}+i\sin{\theta})(\cos{\alpha}+i\sin{\alpha}) &=\cos{(\theta+\alpha)}+i\sin{(\theta+\alpha)} \end{aligned} ( cos θ + i sin θ ) ( cos α + i sin α ) ​ = cos ( θ + α ) + i sin ( θ + α ) ​
즉, 원래의 복소수에 cos ⁡ α + i sin ⁡ α \cos{\alpha}+i\sin{\alpha} cos α + i sin α 라는 복소수를 곱하게 되면, 크기는 유지되나, 그 편각이 θ + α \theta+\alpha θ + α 가 된다.

따라서 원래의 복소수가 나타내는 점을 P \rm P P 라 하고, 그 점을 α \alpha α 만큼 회전 이동시킨 점을 P ′ \rm P' P ′ 라 할 때, P ′ \rm P' P ′ 에 대응되는 복소수는 다음과 같다.

z ′ = z ⋅ ( cos ⁡ α + i sin ⁡ α ) \begin{aligned} z'=z \cdot (\cos{\alpha}+i\sin{\alpha}) \end{aligned} z ′ = z ⋅ ( cos α + i sin α ) ​

이것은 오일러 공식 을 이해했다면 더 쉽게 이해 가능하다.
