1. 개요 [편집]
Fixed-point Theorem

정의역과 공역이 공간 X X X 인 함수 f : X → X f:X\to X f : X → X 에 대하여 x 0 ∈ X x_0\in X x 0 ​ ∈ X 가 f ( x 0 ) = x 0 f(x_0) = x_0 f ( x 0 ​ ) = x 0 ​ 를 만족할 때 이 점 x 0 x_0 x 0 ​ 를 함수 f f f 의 부동점 또는 고정점 (fixed point)이라고 한다.

부동점 정리 [1] 는 공간 X X X 와 함수 f f f 에 적당한 조건 이 주어지면 X X X 내에 f f f 의 부동점이 존재한다는 것을 내용으로 한다. 그 적당한 조건 이 구체적으로 어떤 조건인가에 따라 많은 부동점 정리가 있다. 그중에 해석학 에서 배우는 바나흐의 부동점 정리와 위상수학 에서 배우는 브라우어의 부동점 정리가 잘 알려져 있다.

부동점 정리는 많이 응용되는 도구이다. 대표적으로 립쉬츠 조건을 만족하는 미분방정식 의 해가 존재한다는 정리를 증명할 때 부동점 정리가 사용된다. 또한 다변수해석학에서 역함수 정리 를 증명할 때 사용하기도 한다. 부동점 정리는 수학 이외의 학문에서도 응용되는 경우가 많다. 예를 들자면 경제학 에서 완전경쟁교환경제에 일반균형이 존재함을 증명하는 데에 이용된다. 그리고, 영화 뷰티풀 마인드 로 유명한 존 내시 가 게임이론 에서 내시균형의 존재 정리 를 증명할 때도 부동점 정리가 이용됐다.

부동점 정리는 여럿 있는데, 아래 소개된 둘 외에도 가쿠타니 부동점 정리 , [2] 렙셰츠 부동점 정리 , 아티야-보트 부동점 정리 등이 있다.

2. 바나흐 부동점 정리 [편집]
Banach Fixed-point Theorem / Contraction Mapping Principle

바나흐 부동점 정리의 내용은 다음과 같다. 공집합 이 아닌 완비 거리공간 ( X , d ) (X,d) ( X , d ) 에서 정의된 함수 f : X → X f:X\to X f : X → X 가 축소사상이면 f f f 는 유일한 부동점 x ∗ ∈ X x^*\in X x ∗ ∈ X 를 갖는다. (즉, f ( x ∗ ) = x ∗ f(x^*)=x^* f ( x ∗ ) = x ∗ 이다.)

여기서 함수 f f f 가 축소사상 이라는 것은 임의의 x , y ∈ X x,y\in X x , y ∈ X 에 대하여 상수 0 ≤ α < 1 0\leq\alpha<1 0 ≤ α < 1 가 있어서 d ( f ( x ) , f ( y ) ) ≤ α d ( x , y ) d(f(x),f(y)) \leq \alpha d(x,y) d ( f ( x ) , f ( y )) ≤ α d ( x , y ) 가 항상 성립하는 사상이라는 것을 말한다.

증명은 완비거리공간임을 이용해서 X X X 안의 임의의 점 x 0 x_0 x 0 ​ 로부터 출발하여 x 1 = f ( x 0 ) x_1 = f(x_0) x 1 ​ = f ( x 0 ​ ) , x 2 = f ( x 1 ) x_2 = f(x_1) x 2 ​ = f ( x 1 ​ ) ...의 방식으로 구성한 수열 ( x n ) (x_n) ( x n ​ ) 이 코시수열임 [3] 을 보임으로써 존재성과 유일성을 한꺼번에 보인다. 자세한 것은 해석학 교과서를 참조하면 된다. [4]

3. 브라우어 부동점 정리 [편집]
K ⊂ R n K\subset \mathbb{R}^n K ⊂ R n 를 n n n 차원 유클리드 공간의 볼록 컴팩트 부분집합이라고 하자. 함수 f : K → K f:K\to K f : K → K 가 연속이면 f f f 는 K K K 에서 부동점을 갖는다.

여기서 볼록 컴팩트 부분집합은 단위구 D n = { x ∈ R n : ∥ x ∥ ≤ 1 } D^n = \{ \mathbf{x}\in \mathbb{R}^n : \Vert \mathbf{x}\Vert \leq 1\} D n = { x ∈ R n : ∥ x ∥ ≤ 1 } 로 바꾸어도 무방하다. 위의 바나흐 부동점 정리와는 달리 유일성은 브라우어 부동점 정리의 내용이 아니다.
