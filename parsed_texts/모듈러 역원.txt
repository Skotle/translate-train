1. 개요 [편집]
모듈러 역원 또는 모듈러 역수(modular multiplicative inverse)란 어떤 정수 a a a 와의 곱이 법 [1] m m m 에 대해 1과 합동 이 되게 하는 정수, 즉 a x ≡ 1 ( m o d m ) ax\equiv1\pmod m a x ≡ 1 ( mod m ) [2]

를 만족하게 하는 x x x 를 가리킨다. 모듈러 산술 분야에서는 a − 1 a^{-1} a − 1 로도 표기되는 경우가 있으나 일반적인 의미인 유리수 1 a \cfrac1a a 1 ​ 과 혼동의 여지가 있어 그다지 권장되지는 않는다. 한편, 합동식의 특성상 모듈러 역원이 존재할 경우 모듈러 역원은 원소의 개수가 무한한 집합(동치류)의 형태로 나타나는데, 이를 간단히 a ‾ \overline a a [3] 로 나타내기도 한다. 잉여역원 또는 잉여역수라고도 하며, 윌슨의 정리 증명 시 사용되는 개념이다.

법 m m m 이 소수일 경우, 페르마의 소정리 및 확장된 유클리드 호제법 을 응용한 방법으로 모듈러 역원을 구할 수 있다.

2. 일반항 [편집]
x x x 가 법 m m m 에 대한 a a a 의 모듈러 역원이면 정수 k k k 를 이용하여 x = k m + 1 a x = \dfrac{km+1}a x = a k m + 1 ​

으로 나타낼 수 있으며 [4] , 위 식에서 a a a 와 m m m 은 상수이므로 모듈러 역원은 등차수열 꼴로 나타난다. 예를 들어 법 5 5 5 에 대한 3 3 3 의 모듈러 역원 x x x 는 x = 5 k + 1 3 x = \dfrac{5k+1}3 x = 3 5 k + 1 ​

이며, k = 1 k = 1 k = 1 일 때 정수 2가 얻어지므로, 최종적으로 3의 모듈러 역원은 정수 n n n 을 이용해서 x ‾ = { x ∣ x = 5 n + 2 , n ∈ Z } \overline x = \{x\mid x = 5n+2,\,n\in\Z\} x = { x ∣ x = 5 n + 2 , n ∈ Z } 로 나타낼 수 있다.

3. 성질 [편집]
법 m m m 에 대하여 m m m 과 서로소인 정수 a ≠ 0 a\ne0 a  = 0 의 모듈러 역원은 법 m m m 에 대한 완전잉여계 에 유일하게 존재한다.

3.1. 존재성 [편집]
명제의 역도 성립한다. 즉, a a a 와 m m m 이 서로소이면 a x ≡ 1 ( m o d m ) ax\equiv1\pmod m a x ≡ 1 ( mod m ) 을 만족하는 정수 x x x 가 존재한다.

증명
베주 항등식 에 의해 a x + m y = 1 ax+my=1 a x + m y = 1 을 만족하는 정수 x x x , y y y 가 존재한다. 따라서 a x ≡ 1 ( m o d m ) ax\equiv1\pmod m a x ≡ 1 ( mod m ) 이다.
역으로 a x ≡ 1 ( m o d m ) ax\equiv1\pmod m a x ≡ 1 ( mod m ) 이면 a x − k m = 1 ax-km=1 a x − k m = 1 을 만족하는 정수 k k k 가 존재하므로 베주 항등식 에 의해 gcd ⁡ ( a , m ) = 1 \gcd(a,\,m)=1 g cd ( a , m ) = 1 이다.

3.2. 유일성 [편집]
이제 유일성을 보이자. c c c , d d d 가 법 m m m 에 대한 a a a 의 모듈러 역원이라고 하자. 모듈러 역원의 정의에 의해 a c ≡ a d ≡ 1 ( m o d m ) ac\equiv ad\equiv1\pmod m a c ≡ a d ≡ 1 ( mod m ) 이므로 a c − a d = a ( c − d ) ≡ 0 ( m o d m ) ac-ad = a(c-d)\equiv 0\pmod m a c − a d = a ( c − d ) ≡ 0 ( mod m ) 임을 알 수 있다. 합동식 의 정의에 의해 m ∣ a ( c − d ) m\mid a(c-d) m ∣ a ( c − d ) 이고, gcd ⁡ ( a , m ) = 1 \gcd(a,\,m)=1 g cd ( a , m ) = 1 이므로 m ∣ ( c − d ) m\mid (c-d) m ∣ ( c − d ) 를 얻는다. 따라서 c c c 와 d d d 를 m m m 으로 나눈 나머지는 서로 같다. 즉, c ≡ d ( m o d m ) c\equiv d\pmod m c ≡ d ( mod m ) 이므로 법 m m m 에 대한 a a a 의 모듈러 역원은 법 m m m 에 대한 완전잉여계 에 유일하다. 이것을 모듈러 역원의 유일성이라고 한다.
