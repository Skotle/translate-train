1. 개요 [편집]
암호학 이 대두되면서 큰 소수를 구할 필요가 생겼고, 그와 동시에 큰 합성수의 소인수분해 에 대한 연구도 진행되었다.

2. 알고리즘 [편집]

2.1. 기초 [편집]
주어진 수 N N N 의 소인수를 구한다고 할 경우 우선 가장 간단한 방법은 차례대로 N N N 이 2 2 2 로 나누어떨어지는지, 3 3 3 으로 나누어떨어지는지...를 일일이 반복하는 것이다. 이러한 방법을 Trial Division [1] 이라고 한다. 알고리즘 T (Trial Division) : 정수 N > 1 N > 1 N > 1 을 소인수분해한다.
T1. d ← 2 d \leftarrow 2 d ← 2 .
T2. d 2 > N d^2 > N d 2 > N 이면 T5로 간다.
T3. N m o d d = 0 N \bmod d = 0 N mod d = 0 이면 d d d 를 출력하고, N ← N / d N \leftarrow N/d N ← N / d , T2로 간다.
T4. d ← d + 1 d \leftarrow d + 1 d ← d + 1 . T2로 간다.
T5. N > 1 N > 1 N > 1 이면 N N N 을 출력한다. 종료.

N N N 이 합성수라면 N \sqrt N N ​ 이하의 소인수 p p p 가 존재한다. d 2 > N d^2 > N d 2 > N 이면 d > N d > \sqrt N d > N ​ 이고, d d d 이하의 모든 수로 더 이상 나누어떨어지지 않는 것으로 N N N 은 소수가 된다. 따라서 더 이상 나누어 볼 필요가 없다.

이 알고리즘으로 소인수를 구하면 1000억이 넘는 숫자도 소인수가 순식간에 구해진다.

간단하게 파이썬 으로 코딩 해보면 다음과 같다.
def trial_division ( n ): factors = [] d = 2 while d * d <= n: while n % d == 0 : factors.append(d) n //= d d += 1 if n > 1 : factors.append(n) return factors print (trial_division( 144 )) # [2, 2, 2, 2, 3, 3] print (trial_division( 12345 )) # [3, 5, 823] print (trial_division( 1000000007 )) # [1000000007] (소수) 다만, 위의 프로그램은 프로그래밍을 익히는 용도로는 유용할 수 있으나 실무에서 소인수분해용으로 쓰기에는 적합하지 않다. 실제로 컴퓨터로 다루는 수는 1000억은 '겨우'라는 소리가 나올 만큼 큰 수를 다루기 때문이다.

가장 쉬운 방법은 다른 프로그램을 이용해서 미리 소수 테이블을 작성해 두고, 이를 활용하는 것이다. 예를 들어 2 16 2^{16} 2 16 보다 작은 소수는 6542개인데, 이를 미리 배열에 저장해 두면 42억 ( = 2 32 ) \left(=2^{32}\right) ( = 2 32 ) 보다 작은 수는 겨우 6542번 나누어 보기만 해도 소수인지 판정할 수 있고 1개 이상의 소인수를 구할 수 있다. 2 32 2^{32} 2 32 보다 작은 소수는 모두 약 2억 개( 203,280,221 203{,}280{,}221 203 , 280 , 221 개)인데, 이를 미리 구해서 적절한 DB에 저장해 두면 약 1844 경 ( = 2 64 = 18,446,744,073,709,551,616 ) \left(=2^{64}=18{,}446{,}744{,}073{,}709{,}551{,}616\right) ( = 2 64 = 18 , 446 , 744 , 073 , 709 , 551 , 616 ) 보다 작은 수의 소인수분해를 쉽게 할 수 있다.

20자리 정도 되는 수면 큰 수 라고 생각할 수 있지만, RSA 암호화 같은 암호학 에서는 기본으로 수백 자릿수 정도 되는 수를 다룬다. RSA 넘버 를 보면 가장 작은 수가 100자리인데, 그마저 250자리 수까지는 모두 소인수분해되었다. 가장 큰 RSA-2048은 무려 617자리 수이다. 수의 단위 중 이름이 붙은 최고 단위인 구골 이 101자리 수라는 것을 생각해보면, RSA 암호화에서 다루는 수는 사람에게는 어마어마하게 큰 수이다.
