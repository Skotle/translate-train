1. 개요 [편집]
오일러 피 함수(Euler phi function, Euler totient function) 는 특수함수 의 하나로, 자연수 n n n 에 대해 다음과 같이 정의된다.

φ ( n ) = ∣ { m : 1 ≤ m ≤ n , gcd ⁡ ( m , n ) = 1 } ∣ \varphi(n) = |\{m: 1\le m\le n, \gcd(m,n)=1\}| φ ( n ) = ∣ { m : 1 ≤ m ≤ n , g cd ( m , n ) = 1 } ∣
이름대로 레온하르트 오일러 가 정의한 함수다. 위에서 gcd ⁡ \gcd g cd 는 최대공약수 이고, 따라서 ϕ ( n ) \phi(n) ϕ ( n ) 은 n n n 과 서로소 인 n n n 이하의 자연수의 개수이다.

오일러 피 함수는 당장 이 문서에서도 두가지 표기가 사용되었다. ϕ ( n ) \phi(n) ϕ ( n ) 와 φ ( n ) \varphi(n) φ ( n ) 인데, 수학자들의 공개 온라인 여론조사에서는 후자가 70% 정도 지지받았다. #
