1. 개요 [편집]
라마누잔합 (Ramanujan summation)은 인도의 수학자 스리니바사 라마누잔 이 고안한 발산급수의 합산으로, 1 + 2 + 3 + 4 + ⋯ 1+2+3+4+\cdots 1 + 2 + 3 + 4 + ⋯ 의 제타 정규화(Zeta function regularization) 값이 − 1 12 -\cfrac 1{12} − 12 1 ​ 임을 가리킨다.

2. 분석 [편집]
1 + 2 + 3 + 4 + ⋯ 1+2+3+4+\cdots 1 + 2 + 3 + 4 + ⋯ 은 당연히 무한대 로 발산하므로 특정 실수에 수렴하지 않는다. 일반적인 계산으로 모든 자연수(양의 정수)의 합이 해당 값을 가진다고 말하지 않는다. 다만 해석적 확장을 직관적으로 설명하기 좋은 예시로 본다.

라마누잔은 하나의 수로 가정하고 식을 전개한 뒤, 1 + 2 + 3 + 4 + ⋯ = − 1 12 1+2+3+4+\cdots=-\cfrac 1{12} 1 + 2 + 3 + 4 + ⋯ = − 12 1 ​

이 된다고 직관적으로 계산해 낸다.

사실 라마누잔합이라고 부르는 개념은 이렇게 단순한 것이 아니라서 제대로 알아보려면 복소해석학 을 배워야 한다. 해석적 확장 이라는 개념을 사용하기 때문. 일반적인 덧셈이 아니라 특정 무한급수의 값을 구하는 공식에 범위 외의 값을 대입한 수학적 기법이기 때문에, 당연히 상식적인 계산으로는 도출될 수 없는 결론이다.

2.1. 1−2+3−4+⋯ [편집]
라마누잔은 이를 직관적으로 1 / 4 1/4 1/4 라고 계산했다. 라마누잔의 계산과정은 이곳 에 잘 설명되어 있다. 이를 정리하면 아래와 같다.

3. 그 외 유사한 결과들 [편집]

3.1. 1−1+1−1+⋯ [편집]
앞에서 언급한 무한등비급수 1 + x + x 2 + x 3 + x 4 + ⋯ = 1 1 − x 1+x+x^2+x^3+x^4+\cdots=\cfrac 1{1-x} 1 + x + x 2 + x 3 + x 4 + ⋯ = 1 − x 1 ​

에서 x → − 1 x\to -1 x → − 1 의 극한을 구해 보면, 아래와 같다. 1 − 1 + 1 − 1 + ⋯ = 1 1 + 1 = 1 2 ( ℜ ) 1-1+1-1+\cdots=\cfrac 1{1+1}=\cfrac 12\,(\Re) 1 − 1 + 1 − 1 + ⋯ = 1 + 1 1 ​ = 2 1 ​ ( ℜ )

앞의 것과 마찬가지로 ∣ x ∣ < 1|x|<1 ∣ x ∣ < 1 에서 정의되므로, 원칙적으로는 정의되진 않는다. 하지만, 정의된다고 가정하면 그 값은 1 / 2 \bm 1/2 1 /2 이다 .

참고로, 이 급수는 그란디 급수 란 이름이 있으며 라마누잔합은 '이렇게 부분합이 수렴하지 않는 무한급수의 값은 어떻게 정의할 수 있을까?'란 질문에 답하기 위해 개발된 기법중 하나다.

3.2. 1+2+4+8+16+⋯ [편집]
앞에서 언급한 무한등비급수 1 + x + x 2 + x 3 + x 4 + ⋯ = 1 1 − x 1+x+x^2+x^3+x^4+\cdots=\cfrac 1{1-x} 1 + x + x 2 + x 3 + x 4 + ⋯ = 1 − x 1 ​

에서 x → 2 x\to 2 x → 2 의 극한을 구해 보면, 아래와 같다. 1 + 2 + 4 + 8 + 16 + ⋯ = 1 1 − 2 = − 1 ( ℜ ) 1+2+4+8+16+\cdots=\cfrac 1{1-2}=-1\,(\Re) 1 + 2 + 4 + 8 + 16 + ⋯ = 1 − 2 1 ​ = − 1 ( ℜ )

앞의 것과 마찬가지로 ∣ x ∣ < 1|x|<1 ∣ x ∣ < 1 에서 정의되므로, 원칙적으로는 정의되진 않는다. 하지만, 정의된다고 가정하면 그 값은 −1이다 .

4. 제타 함수 와의 관계 [편집]
이 직관과는 거리가 먼 결과들은 나중에 제타 함수 와 연관성이 발견되면서 재평가를 받는다.

리만 가설 의 바로 그 베른하르트 리만 은 소수 정리 를 연구하면서 리만 제타 함수 라는 것을 만드는데 아래와 같다. ζ ( x ) = ∑ n = 1 ∞ 1 n x \displaystyle \zeta(x)=\sum_{n=1}^\infty\frac 1{n^x} ζ ( x ) = n = 1 ∑ ∞ ​ n x 1 ​

이 식은 원래 실수 중에서 x > 1 x>1 x > 1 일 때만 수렴하는 식이다. 리만은 이를 복소수로 확장하여 x x x 의 실수부가 1보다 크기만 하면 수렴한다고 증명했다. 그리고, 그렇지 않은 x x x 에 대해서도 연구하기 시작한다. 그리고, 방정식 ζ ( x ) = 0 \zeta(x)=0 ζ ( x ) = 0 에 대해서 −2, −4, −6, −8, ⋯ \cdots ⋯ 등의 해가 있음(자명한 근)을 증명했고, 자명하지 않은 근이 존재함도 밝혔는데, '자명하지 않은 근의 실수부는 모두 1 / 2 1/2 1/2 이다.'가 그 유명한 리만 가설 이다.

참고로, 리만 제타 함수에 x = − 1 x=-1 x = − 1 을 대입하면 바로 위의 그 식이 나오며, 리만 제타 함수에서도 이 값은 ζ ( − 1 ) = 1 + 2 + 3 + 4 + ⋯ = − 1 12 \zeta(-1) = 1+2+3+4+\cdots=-\cfrac 1{12} ζ ( − 1 ) = 1 + 2 + 3 + 4 + ⋯ = − 12 1 ​

이 나온다.

5. 활용 [편집]
의외로 물리에서 활용이 된다. ∣ x ∣ > 1|x|>1 ∣ x ∣ > 1 에서 정의 안됐다고 하는 것을 억지로 정의됐다고 가정하고 푸는 것이 라마누잔합의 뼈대인데, 물리에서는 수식이 말이 안됨에도 실측값이 존재(해야)하기 때문에 특정 값을 끼워넣어야 하는 경우가 종종 있기 때문. 개요에서 잠깐 언급되었듯이 이렇게 정의역을 확장시키는 것을 수학적으로 해석적 연속 이라고 부르며, 이러한 접근은 물리에서 섭동을 전개할 때 원치 않는 발산이 일어날 경우 무한대로부터 수렴값을 얻는 데 사용되는 테크닉인 재규격화 및 조절의 토대가 된다.

라마누잔합이 활용되는 직접적이면서 대표적인 예시로 카시미르 효과 가 있다. 간단히 말하면 진공 사이에 두 철판을 두면 갑자기 어디선가 에너지가 생긴다는 것. 양자장론 에 따르면 철판으로 인한 경계조건 에 의해 그 사이에 양자적 정상파가 생기는데, 이때 진동수가 자연수인 모든 정상파가 존재할 수 있으므로 각 정상파의 에너지의 합을 계산하면 발산해야하지만 라마누잔합이 이를 억눌러 의미가 있는 어떤 값이 나온다. 그리고 위에서 설명하듯 이 합은 음수이므로 철판 사이의 에너지는 음의 에너지, 즉 인력이 작용한다는 것. [2] #

또한 초끈 이론 에서도 보손 들을 설명하는 끈(bosonic string)의 바닥 에너지를 구할 때도 이들이 진동자라는 점과 바닥 에너지는 가능한 모든 정상파의 에너지의 합이라는 점을 이용해 라마누잔합을 적용한다. 다만 이쪽은 완전히 정립된 이론도 아니고, 이 전개를 계속 따라갈 경우 우주의 차원이 26차원이 된다는, 받아들여지기 힘든 결과를 내기 때문에 아직까진 크게 의미있는 이론은 아니다.
