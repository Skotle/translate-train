1. 개요 [편집]

폴란드계 프랑스인 수학자인 브누아 망델브로 [2] 가 고안한 프랙털 의 일종으로, 다음과 같은 점화식 으로 표현되는 수열 { z n } \{z_n\} { z n ​ } 의 절댓값이 무한대로 발산 하지 않는 복소수 c의 집합으로 정의된다. z 0 = 0 z n + 1 = z n 2 + c \begin{aligned} z_0 &= 0 \\ z_{n+1} &=z_n^2+c \end{aligned} z 0 ​ z n + 1 ​ ​ = 0 = z n 2 ​ + c ​
예를 들어 c = 1 c=1 c = 1 이라면 수열 { z n } \{z_n\} { z n ​ } 은 0 , 1 , 2 , 5 , 26 , . . . 0, 1, 2, 5, 26,\;... 0 , 1 , 2 , 5 , 26 , ... 이고 lim ⁡ n → ∞ ∣ z n ∣ = ∞ \displaystyle \lim_{n\to \infty} \left| z_n \right| = \infty n → ∞ lim ​ ∣ z n ​ ∣ = ∞ 이므로 1은 망델브로 집합에 포함되지 않는다. 한편 c = − 1 c=-1 c = − 1 이라면 { z n } \{z_n\} { z n ​ } 은 0 , − 1 , 0 , − 1 , 0 , . . . 0, -1, 0, -1, 0,\;... 0 , − 1 , 0 , − 1 , 0 , ... 이고 음이 아닌 모든 정수 n n n 에 대해 ∣ z n ∣ ≤ 1 \left| z_n \right| \leq 1 ∣ z n ​ ∣ ≤ 1 이므로 -1은 망델브로 집합에 포함된다.

이런 c의 집합을 복소평면 에 나타내면 위와 같은 도형이 나타난다. 비전공자에게 왜 이런 모양이 나오는지 간략히 설명한다면, 임의의 복소수 c에 대해서 해당 수열을 복소평면에 찍으면 특정 점을 기준으로 절댓값이 일정한 비율로 증가 혹은 감소하는 나선형 형태로 나타나기 때문이다. c = − 1 c=-1 c = − 1 의 예시로 다시 돌아가보면 이 경우에는 − 0.5 + 0 i -0.5 + 0i − 0.5 + 0 i 를 기준으로 거리가 0.5에서 변하지 않으며 한번에 180도씩 회전하는 형태라고 할 수 있다.

2. 그리기 [편집]
실제로 망델브로 집합을 그릴 때는 무한한 항까지 계산하여 발산 여부를 확인하는 것이 어려우므로 '어떤 n n n 에 대해 ∣ z n ∣ > 2 \left| z_n \right|>2 ∣ z n ​ ∣ > 2 일 경우 { z n } \{z_n\} { z n ​ } 은 발산한다'는 성질을 이용한다. 즉, 수열을 계산하다가 절댓값이 2를 넘는 점을 배제하고 그리면 된다. 이러한 성질을 이용하더라도 집합에 포함되는 점은 무한히 계산해도 발산하지 않기 때문에, 보통 특정한 n n n 의 값을 정하고 그 값까지만 계산한다. 따라서 n n n 이 클수록 완성된 그림의 정확도도 높아진다.

수학적으로는 어떤 점이 망델브로 집합에 포함되거나 포함되지 않거나의 두 가지 경우밖에 없으므로 흑백으로만 그려도 상관은 없지만, 대부분의 경우 처음으로 ∣ z n ∣ \left| z_n \right| ∣ z n ​ ∣ 이 2 2 2 를 넘는 n n n 의 값에 따라 배경에 색을 칠한다.

4. 여담 [편집]
가수 서태지 의 6집 앨범 재킷 디자인에 사용되었다.
가수 노라조 의 노래 니팔자야 의 뮤직비디오 초반에 위 도형의 프랙털 전개가 나온다. 확대될수록 계산의 한계로 x 축(실수부 축)의 띠 부분이 점점 두꺼워지는데 이 두꺼운 띠 안에 이혁 조빈 콤비가 있는 걸로 본격적인 노래 시작.

고안자의 성씨인 '망델브로(Mandelbrot)'는 아몬드 빵이라는 뜻이다. 이 아몬드 빵 과는 관계없다.
