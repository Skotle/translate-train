1. 개요 [편집]
수학에서 완비성( 完 備 性 , completeness)은 어떤 공간이 '빈 틈 없이 메워져 있음'을 의미한다. 완비성을 갖는 공간 안에서는 극한 의 수렴성을 논하는 것이 가능해, 해석적 방법 을 이용하여 공간의 성질과 공간에서 정의된 함수 를 분석할 수 있다. 완비성을 갖는 대표적인 공간으로 완비 순서체인 실수체 가 있다.

2. 정의 [편집]

2.1. 거리공간의 완비성 [편집]
거리함수 d : X × X → [ 0 , ∞ ) d:X\times X\to[0,\infty) d : X × X → [ 0 , ∞ ) 가 주어진 거리공간 ( X , d ) (X,\,d) ( X , d ) 에 대하여, 임의의 ϵ > 0 \epsilon>0 ϵ > 0 에 대하여

쉽게 말해 코시열은 점렬의 점 사이의 거리가 계속해서 무한히 가까워 지는 점렬이다. 따라서 코시열은 나아갈수록 무한히 작아지는 반경 안을 떠돈다.

완비성을 가진 거리공간 ( X , d ) (X,\,d) ( X , d ) 은 X X X 안의 모든 코시열이 그 공간 내에서 수렴하는 [1] 것으로 정의된다.
수렴하는 점렬은 모두 코시열이지만, 모든 코시열이 수렴하는 것은 아니다. 완비거리공간은 코시열과 수렴하는 수열이 동치인 거리공간이다.

3. 예시 [편집]

3.1. 수체 [편집]
유리수체, 실수체, 복소수체는 자기 자신 위의 1차원 벡터공간 이다. 이때, 유리수체와 실수체는 수의 절댓값, 복소수체는 복소수의 크기를 각각 노름 으로 가지므로 노름공간 이며, 노름은 자연스러운 거리를 유도하므로 각 수체는 거리공간 이다. 따라서 각 수체의 완비성을 판별할 수 있다.

3.1.1. 유리수체 [편집]
유리수체 Q \mathbb{Q} Q 는 완비성을 갖지 않는다. 집합 S = { x ∈ Q : x 2 < 2 } S=\left\{x\in\mathbb{Q}:x^2<2\right\} S = { x ∈ Q : x 2 < 2 } 는 임의의 x ∈ S x\in S x ∈ S 에 대하여 x < 2 x<\sqrt 2 x < 2 ​ 이므로 위로 유계인 집합이지만 sup ⁡ S = 2 ∉ Q \sup S=\sqrt{2}\notin\mathbb{Q} sup S = 2 ​ ∈ / Q 이다.
