1. 개요 [편집]
選 擇 公 理 / axiom of choice

선택공리는 ZFC 공리계 의 공리 중 하나이다. [1] 약칭으로 AC라고도 한다. 수학자들이 암암리에 해당 공리를 쓰고 있음을 체르멜로가 발견하고 이를 명시했다. [2] 아래 항목에서 확인할 수 있듯 매우 강력한 공리이므로 위상 수학 , 대수학 등 수학의 여러 분야에서 쓰인다. 언뜻 보기에는 무척 직관적이고 자명해 보이는 공리지만 선택공리를 토대로 논리를 발전시키다 보면 직관과 정면으로 충돌하는 괴상한 결과들이 얻어져 선택 공리를 거부하는 수학자도 있다.

선택 공리는 대표적인 비구성적 명제이다. 즉, 선택 함수의 존재성은 보장해 주지만 그 함수가 어떻게 주어지는지는 알려 주지 않는다. 이 때문에 구성주의자나 직관주의자들은 이 공리를 거부하거나 수정된 버전을 받아들인다. [3] 다음 문단의 식에서 집합 F \mathcal{F} F 를 가산 집합으로 한정한 가산 선택 공리(axiom of countable choice) 등, 보다 약한 버전을 쓰는 경우로 타협하는 경우가 대부분이지만, 그것마저 배제하는 극단주의자들도 있다고 한다. 이처럼 수학에서 수정된 선택 공리를 사용하는 것이 가능한 이유는 선택 공리가 참이든 거짓이든 ZF 공리계와 양립 가능하기 때문이다.

여담으로 결정 공리(axiom of determinacy)라는게 있는데, 이 결정 공리는 자연수열 공간에서 취하는 모든 부분 집합은 결정집합 [4] 이라는 공리로, 선택 공리와 공존할 수 없는 공리 [5] 이지만, 약화시킬 경우는 선택 공리와 동일시할 수 있는 특이한 성질을 지니고 있다. 약화되지 않은 결정 공리를 ZF 공리계에 포함시켜도 모순은 발생하지 않기 때문에 ZF 공리계의 일관성이 보장된다는 것 또한 특기할 사항이다.

3. 해석 [편집]
임의의 집합족 F \mathcal{F} F [6] 대해, F \mathcal{F} F 의 모든 원소가 공집합 이 아니라면, F \mathcal{F} F 의 각 원소(집합이다.)마다 그 집합의 원소를 하나씩 뽑는 선택 함수(choice function)가 존재한다는 뜻이다.

예를 들면 집합족 F = { { 0 , 1 } , { 2 , 3 , 4 } , { 4 , 6 , 7 } , … } \mathcal{F} = \{ \{ 0, 1 \}, \{ 2, 3, 4 \}, \{ 4, 6, 7 \}, \dots \} F = {{ 0 , 1 } , { 2 , 3 , 4 } , { 4 , 6 , 7 } , … } 에 대해, 첫 번째 집합에서 0 0 0 을 뽑고, 두 번째 집합에서 3 3 3 를 뽑고, 세 번째 집합에서 7 7 7 을 뽑는 등의 선택을 동시에 할 수 있다는 뜻이다. 다만, 선택 공리 자체는 선택 함수의 존재성만 보일 뿐, 이 예시에서처럼 각 집합에서 어떤 원소가 선택되었는지를 말해주지는 않는다.

막상 이렇게 설명하면 너무 당연해서 선택 공리를 거부하는 일부 수학자들을 이해하기 힘들 수도 있지만 [7] , 사실 자명해 보이는 것은 F \mathcal{F} F 가 유한 집합일 때(즉, 유한 번만 뽑을 때)뿐이다. F \mathcal{F} F 가 무한 집합인 경우, 특히 R \R R 처럼 비가산 집합인 경우에는 생각보다 그렇게 자명하지 않다. 또한 후술할 선택 공리와 동치인 명제들을 보면 비직관적인 내용이 많음을 알 수 있다.

사실 극도로 추상적인 분야가 아닌 이상 대부분 선택 공리 없이 선택 함수를 직접 구성할 수 있는 경우를 다루게 된다. 예를 들어 각 실수가 집합임을 일단 받아들이고 [8] , 실수 x x x 에 대해 U x ≔ [ x , + ∞ ) U_x \coloneqq [x, +\infty) U x ​ : = [ x , + ∞ ) 라고 정의한 후, 집합족 { U x ∣ x ∈ R } \{ U_x \mid x \in \R \} { U x ​ ∣ x ∈ R } 를 생각하자. 여기서 선택 함수 f : U x ↦ x + 3 , x ∈ R f: U_x \mapsto x + 3, x \in \R f : U x ​ ↦ x + 3 , x ∈ R 를 다음과 같이 구성할 수 있다. 먼저 각 실수 x x x 마다 x + 3 x + 3 x + 3 도 집합이므로 짝 공리와 분류 공리를 이용하여 순서쌍 ( U x , x + 3 ) = { { U x } , { U x , x + 3 } } (U_x, x + 3) = \{ \{ U_x \}, \{ U_x, x + 3 \} \} ( U x ​ , x + 3 ) = {{ U x ​ } , { U x ​ , x + 3 }} 을 만들 수 있다. 이후 치환 공리를 이용하면 집합 { ( U x , x + 3 ) ∣ x ∈ R } \{ (U_x, x + 3) \mid x \in \R \} {( U x ​ , x + 3 ) ∣ x ∈ R } 를 만들 수 있고, 이로 f f f 를 구성할 수 있다.

하지만 선택 공리의 강력함은, 위의 예시와는 다르게 집합족이 도대체 어떻게 생겨먹은 것인지 모르는 경우에도, 선택 함수가 항상, 반드시 존재한다 는 사실을 보장해 준다는 점이다. 그러나 이는 동시에 선택 공리의 한계이기도 한데, 예를 들어 유한 차원 F F F 벡터 공간의 경우, 선택 공리 없이도 존재하는 기저와 차원을 이용하면 동형이면서 많은 성질이 알려진 F n F^n F n 으로 생각할 수 있다. 반면 기저를 알 수 없는 무한 차원 벡터공간(예를 들어 연속 실함수의 공간)의 경우에는 선택 공리를 가정하면 기저는 항상 존재하고 차원이 잘 정의되지만, 그것만으로는 주어진 공간에 대해 알 수 있는 내용이 거의 없고 위상이나 측도 등의 추가적인 구조가 있어야 적절한 이해가 가능하다.

선택 공리를 서술할 때는 함수라는 개념이 사용된다. 공집합을 포함하지 않는 임의의 집합족 F \mathcal{F} F 에 대해, F \mathcal{F} F 의 선택 함수가 존재한다. 하지만 선택 공리는 집합이 무엇인지를 정의하기 위한 공리이므로 함수처럼 집합으로 정의되는 개념을 먼저 사용할 수 없다. 그래서 선택 공리를 일차 논리만으로 적으려면 약간의 변형이 필요하다. 먼저 다음 명제를 생각하자. 임의의 집합 A A A 의 임의의 분할 F \mathcal{F} F [9] 에 대해, F \mathcal{F} F 의 선택 함수가 존재한다. 이는 표면적으로는 앞의 선택 공리보다 약한 명제인데, 특정한 집합족에 대해서만 선택 함수의 존재성을 보장해 주기 때문이다. 하지만 이는 사실 처음 본 선택 공리와 동치이다. 어떤 집합의 분할이 되려면 (1) 공집합을 포함하지 않고 (2) 모든 원소가 쌍으로 서로소이면 된다. 이를 반영하면 선택 공리를 다음과 같이 변형할 수 있다. 공집합을 포함하지 않고, 각 원소가 쌍으로 서로소인 임의의 집합족 F \mathcal{F} F 에 대해, F \mathcal{F} F 의 선택 함수가 존재한다. 이제 함수를 모사할 수만 있으면 되는데, 집합족이 분할임을 이용하면 치역이 그 역할을 할 수 있음을 떠올릴 수 있다. 즉, 치역 R R R 만 있으면 F \mathcal{F} F 의 각 원소 A A A 마다 R ∩ A R \cap A R ∩ A 가 f ( A ) f(A) f ( A ) 의 값만 포함하므로 원래의 선택 함수 f f f 를 구성할 수 있다. 이를 반영하면 선택 공리는 다음과 같이 변형할 수 있다. 공집합을 포함하지 않고, 각 원소가 쌍으로 서로소인 임의의 집합족 F \mathcal{F} F 에 대해, F \mathcal{F} F 의 각 원소 A A A 마다 R ∩ A R \cap A R ∩ A 가 단집합(singleton)인 집합 R R R 가 존재한다. 4. ZF 공리하에서 선택 공리와 동치인 명제들 [편집]
- 모든 분할 은 대표값의 집합을 가진다.
- 임의의 무한 집합 X X X 에 대해 ∣ X ∣ = ∣ X 2 ∣|X| = \bigl| X^2 \bigr| ∣ X ∣ = ​ X 2 ​ 이다. [12] 이를 일반화하면 ∀ k ∈ N ∣ X ∣ = ∣ X k ∣ \forall k \in \N ~ |X| = \bigl| X^k \bigr| ∀ k ∈ N ∣ X ∣ = ​ X k ​ 이다. 즉, 임의의 무한 집합은 자기 자신과의 유한 데카르트 곱과 일대일 대응 관계를 가진다.
- 초른의 보조정리 (Zorn’s lemma): 부분 순서 집합의 임의의 사슬이 상계를 가지면 극대 원소가 적어도 하나 존재한다.
- 정렬 정리(well-ordering theorem) [13] : 공집합이 아닌 모든 집합에 정렬 순서를 줄 수 있다. [14] 이 또한 선택 공리와 동치이다. 이에 따라 모든 집합에 적절한 순서대로 순서수를 배분하는 게 가능해지면서 초한 귀납법이 가능해진다.
- 티호노프 정리 : 콤팩트 집합의 곱 공간 [15] 은 콤팩트이다.
- 모든 벡터 공간 은 기저를 가진다. [16]
- 모든 전사 함수 는 우 역원을 가진다.
- 공집합이 아닌 집합들끼리의 데카르트 곱은 공집합이 아니다. [17]
- 공집합이 아닌 집합에 적절한 이항 연산 을 줘서 군을 만들 수 있다.

5. 선택 공리의 결과들 [편집]
- 모든 무한 집합은 가산 부분 집합을 가진다.
- 모든 집합에 대해 기수 가 잘 정의된다.
- 가산 개의 가산 집합의 합집합은 가산 집합이다.
- 함수의 치역의 기수는 정의역보다 작거나 같다.
- 코시 함수 방정식 f ( x + y ) = f ( x ) + f ( y ) f(x + y) = f(x) + f(y) f ( x + y ) = f ( x ) + f ( y ) 를 만족하면서도 일차 함수가 아닌 함수 f : R → R f: \R \to \R f : R → R 가 존재한다.
- 한·바나흐 정리
- 르베그 측도 를 가지지 않는 집합이 존재한다.
- 1 1 1 을 가지는 가환 환은 극대 아이디얼을 가진다.
- 모든 그래프는 최대 경로를 가진다.
- 모든 체 는 대수적 닫힘(algebraic closure)을 가진다. [18]
- 바나흐·타르스키 역설 [19] : 구를 유한 개의 조각으로 잘 쪼갠 다음, 그 조각들을 다시 잘 붙여서 원래 구와 같은 크기의 구 두 개로 재구성할 수 있다. 이때 나눠진 각 조각 중 르베그 측도 를 갖지 않는 집합이 생긴다. [20]
- 임의의 무한 집합에 자유 극대 필터가 존재한다. [21]
- 순서 확장 정리: 모든 부분 순서에는 순서 관계를 보존하는 전순서가 존재한다.
- 주 이데알 정역 위의 자유 가군의 부분 가군은 자유 가군이다.
- 3차원 공간을 서로 겹치지 않는 단위원, 또는 서로 겹치지 않고 크기가 전부 다른 원, 또는 서로 평행하지 않은 직선들로 완벽히 채울 수 있다. [22]

8. 여담 [편집]
개요에서 보여지듯 원래 ZFC 에서 ZF만 먼저 발표되었고 나중에 C가 추가되었다. 문제는 이 추가된 C가 ZF 내에서 증명도 반증도 불가능한 불완전성 정리 의 완벽한 예시라는 점이다.

괴델 은 연속체 가설 과 선택 공리가 각각 ZF 공리계와 일관적임을 1938년에 증명했다. 이때 사용된 것이 상술한 구성가능성 공리 이다. 이후 폴 코헨 은 1963년 연속체 가설과 선택 공리의 부정이 각각 ZF 공리계와 일관적임을 증명했다. 즉, ZF 공리계를 받아들일 때 C는 받아들여도 일관적이고 받아들이지 않아도 일관적이다. 개요에서 간단히 언급된 ‘선택공리에 대한 수정’이 가능한 이유이다.

이처럼 선택 공리를 사람에 따라 받아들일 수도, 받아들이지 않을 수도 있다 보니 이런 농담도 생겨났다. 수학자들의 파티에서 서로 자기가 아는 무서운 이야기를 하고 있었다. 한 수학자가 ‘선택 공리가 거짓이라고 해보자…’라고 하니 해석학, 위상 수학 분야의 수학자들이 거품을 물고 쓰러졌다. [26] [27]

The axiom of choice is obviously true, the well-ordering principle obviously false, and who can tell about Zorn’s lemma?
선택 공리는 당연히 참이고, 정렬 원리는 당연히 거짓이다. 초른의 보조정리가 참인지 거짓인지는 누가 알 수 있겠는가?

선택 공리는 상식적으로 참인 느낌이고 정렬 정리는 상식적으로 거짓인 느낌인데, 이들이 동치이다 보니 이와 관련된 농담도 있다. #
