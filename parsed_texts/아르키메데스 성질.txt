1. 개요 [편집]
Archimedean property

자연수 와 실수 의 근본적인 성질 중 하나로, 보통 정수론 또는 공리적 해석학 을 처음 배울 때 등장한다.

2. 진술 [편집]
임의의 ε > 0 \varepsilon>0 ε > 0 , M ∈ R M\in \mathbb R M ∈ R 에 대해 N ε > M N\varepsilon>M N ε > M 을 만족하는 자연수 N N N 이 존재한다.

정수에 관한 정리이긴 하지만 엄밀하게는 실수 의 성질도 필요하다. M M M 이 유리수 한정으로 되어 있는 버전도 있는데, 이 버전은 페아노 공리계 만 갖고 증명이 가능하다.

3. 증명 [편집]
실수의 완비성 을 이용하여 귀류법으로 증명할 수 있다. 아래는 자세한 내용.
먼저 임의의 자연수 N N N 에 대해, N ε < M N\varepsilon < M N ε < M 이라 가정하자. 그러면 S : = { n ε ∣ n ∈ N } S:=\left\{n\varepsilon \ |n\in \mathbb{N}\right\} S := { n ε ∣ n ∈ N } 은 상계를 갖는다. 집합 S S S 는 공집합 이 아닌 실수의 부분집합이므로, 완비성 공리에 의하여 최소상계 μ = sup ⁡ S \mu=\sup S μ = sup S 가 존재한다.

sup ⁡ S \sup S sup S 의 정의에 의해, μ − ε \mu-\varepsilon μ − ε 은 집합 S S S 의 상계가 아니므로 μ − ε < n ε \mu-\varepsilon <n\varepsilon μ − ε < n ε 인 자연수 n n n 이 존재한다. 그러면 μ < ( n + 1 ) ε \mu <(n+1)\varepsilon μ < ( n + 1 ) ε 이 성립하고, n n n 이 자연수이면 n + 1 n+1 n + 1 도 자연수이므로 이는 곧 μ < m ε \mu<m\varepsilon μ < m ε 인 자연수 m m m 이 존재한다는 것을 의미한다. 다시 말해 S S S 의 원소 중 최소상계 μ = sup ⁡ S \mu = \sup S μ = sup S 보다 큰 것이 존재하며, 이는 sup ⁡ S \sup S sup S 의 정의에 모순이다. 따라서 집합 S S S 는 상계를 가지지 않는다. 즉, 임의의 실수 M M M 에 대해 N ε > M N\varepsilon>M N ε > M 을 만족하는 자연수 N N N 이 존재한다.

4. 활용 [편집]
아르키메데스 성질을 이용하면 수열 { 1 n } \displaystyle \left\{\frac{1}{n}\right\} { n 1 ​ } 이 0으로 수렴함을 보일 수 있다.
증명 아르키메데스 성질에 의해 임의의 양수 ε \varepsilon ε 에 대하여 N ε > 1 N\varepsilon>1 N ε > 1 인 자연수 N N N 이 존재한다. 그러면 1 N < ε \displaystyle \frac{1}{N}<\varepsilon N 1 ​ < ε 이므로 n ≥ N n\geq N n ≥ N 인 임의의 자연수 n n n 에 대하여 ∣ 1 n ∣ < ε \displaystyle \left|\frac{1}{n}\right|<\varepsilon ​ n 1 ​ ​ < ε 이 성립한다. 따라서 lim ⁡ n → ∞ 1 n = 0 \displaystyle \lim_{n\to \infty}\frac{1}{n}=0 n → ∞ lim ​ n 1 ​ = 0 이다.

또한 아르키메데스 성질에서 ε = 1 \varepsilon=1 ε = 1 로 놓으면 임의의 실수 M M M 에 대해 N > M N>M N > M 을 만족하는 자연수 N N N 이 존재한다는 진술이 되므로 이를 통해 자연수 집합이 유계가 아님을 보일 수 있다.

5. '비(非)' 아르키메데스 성질? [편집]
아르키메데스의 성질은 절대값 을 이용해 종종 다음과 같은 식으로 설명된다. 임의의 0이 아닌 x ∈ Q x \in \mathbb{Q} x ∈ Q 에 대해 ∣ N x ∣ > 1|Nx|>1 ∣ N x ∣ > 1 을 만족하는 자연수 N N N 이 존재한다.

절대값 을 유리수 위의 삼각부등식 을 만족하는 거리함수로 간주하면, 아르키메데스 성질은 정수 자체에 대한 것이 아니라 절대값이라는 '거리함수'에 대해 성립하는 성질로 생각될 수 있다. 굳이 이렇게 번거롭게 돌아가는 이유는, 유리수에는 아르키메데스 성질이 성립하지 않는 거리함수도 있기 때문이다.

소수 p에 대해 p진 거리 (p-adic distance)는 다음처럼 정의된다. 0이 아닌 모든 유리수 q q q 는 정수 e e e 와 p p p 와 p와 서로소인 정수 a , b a,b a , b 에 대해 q = p e ( a / b ) q = p^e (a/b) q = p e ( a / b ) 로 나타낼 수 있다. 이 때 q q q 의 거리를 ν p ( q ) = p − e \nu_{p}(q) = p^{-e} ν p ​ ( q ) = p − e 로 정의한다. ν p ( 0 ) = 0 \nu_p(0) = 0 ν p ​ ( 0 ) = 0 으로 정의한다. 예시) p = 3 p=3 p = 3 에 대해 ν 3 ( 1 ) = ν 3 ( 2 ) = ν 3 ( 4 ) = 1 \nu_{3} (1)=\nu_3(2)=\nu_3(4)=1 ν 3 ​ ( 1 ) = ν 3 ​ ( 2 ) = ν 3 ​ ( 4 ) = 1 , ν 3 ( 3 ) = ν 3 ( 6 ) = 1 / 3 \nu_3 (3)=\nu_3(6)=1/3 ν 3 ​ ( 3 ) = ν 3 ​ ( 6 ) = 1/3 , ν 3 ( 1 / 243 ) = 243 \nu_3(1/243) = 243 ν 3 ​ ( 1/243 ) = 243 통상적인 절대값 과는 좀 많이 다르지만, 이 p진 거리도 삼각부등식 ν p ( x + y ) < ν p ( x ) + ν p ( y ) \nu_p (x+y) < \nu_p(x) + \nu_p(y) ν p ​ ( x + y ) < ν p ​ ( x ) + ν p ​ ( y ) 을 만족한다. 심지어는 더욱 강력한 성질인 ν p ( x + y ) ≤ max ⁡ ( ν p ( x ) , ν p ( y ) ) \nu_p (x+y) \le \max( \nu_p(x), \nu_p(y)) ν p ​ ( x + y ) ≤ max ( ν p ​ ( x ) , ν p ​ ( y )) 가 성립한다! 절대값에서 성립하는 곱의 공식 ∣ x y ∣ = ∣ x ∣ ∣ y ∣|xy|=|x||y| ∣ x y ∣ = ∣ x ∣∣ y ∣ 도 그대로 옮겨가 ν p ( x y ) = ν p ( x ) ν p ( y ) \nu_{p}(xy)= \nu_{p}(x) \nu_{p}(y) ν p ​ ( x y ) = ν p ​ ( x ) ν p ​ ( y ) 가 성립한다. 즉 p진 거리는 유리수 위의 절대값이 갖추는 요건을 모두 갖추고 있다. 아르키메데스 성질 하나만 빼고. 자연수 N N N 에 대해 ν p ( N ) ≤ 1 \nu_p (N) \le 1 ν p ​ ( N ) ≤ 1 이므로 ν p ( N x ) ≤ ν p ( x ) \nu_p(Nx) \le \nu_p(x) ν p ​ ( N x ) ≤ ν p ​ ( x ) 가 되어, 아르키메데스 성질은 '항상' 성립하지 않는다.

유리수 체 위에 정의된 노름(norm, 곱에 의해 보존되는 거리함수)은 아르키메데스 성질을 만족시키는 절대값과 아르키메데스 성질을 만족시키지 않는 이들 p진 거리가 전부이다. 이를 일반화하여 정수론 에서는 아르키메데스 성질을 만족시키는 노름을 아르키메데스 거리(Archimedean metric), 그렇지 않은 것을 비 아르키메데스 거리(non-Archimedean metric)이라 부른다. 보통 아르키메데스 거리들은 절대값에서 유도되고 비 아르키메데스 거리들은 p진 거리에서 유도되기 때문에, 이 아르키메데스 성질을 만족하는지 아닌지의 여부로 양자택일이 되는 것이다.
